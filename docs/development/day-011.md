# 11일차: 잠긴 문과 열쇠

---
## 구현 내용

- 기존 규칙에 따라 열쇠가 없으면 잠긴 문을 열 수 없고, 열쇠 한 개를 소모해 양방향 잠금 해제.
- 이동 도중 도착 칸이 막히면 사용을 예약한 열쇠와 문 잠금을 복구.
- 일반 말단 방 연결 하나에 보라색 시험 잠긴 문을 배치하고, 적합한 말단 방이 없으면 배치 생략.
- 인벤토리에서 개발 확인용 열쇠 지급과 보유 수량 표시, 층 이동 시 열쇠 유지와 새 게임 초기화.
- 기준: [기존 문 규칙](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Domain/GridPassage.cs).

---
## 범위

시험 열쇠 지급과 시험 잠긴 문은 개발 확인용이다. 정식 열쇠 획득과 잠금 배치, 저장은 후속 작업이다. 기존 코드에서 강제 개방 규칙을 확인하지 못해 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트의 EditMode 테스트 81개 통과.
- PlayMode 테스트 43개 통과, 열쇠 부족·지급·이동 실패 복구·양방향 이동 검증.
- 잠긴 문 실제 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
