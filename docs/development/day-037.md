# 37일차: SD 주인공 방향별 이미지

---
## 구현 내용

- 기존 SD 주인공을 기준으로 뒤·왼쪽·오른쪽 투명 이미지 제작.
- 실제 이동 방향에 따라 네 방향의 주인공 이미지 전환.
- 방향 화살표를 유지하고 사용자 지정 플레이어 이미지는 자동 변경하지 않음.
- 위쪽 이동 중 실제 플레이 화면을 README에 갱신.

---
## 범위

각 방향은 한 장의 정지 이미지이며 프레임 기반 걷기 애니메이션은 아직 적용하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 99개 통과.
- 키보드·게임패드 이동의 네 방향 이미지와 사용자 지정 이미지 보존 검증.
- 실제 위쪽 이동 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
