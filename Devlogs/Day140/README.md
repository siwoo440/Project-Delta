# 140일차 : NPC 상호작용·상점 화면 정식 UI 전환

## 목표
- 기획서 8.2절 "화면별 정식 UI" 전환 - 139일차(타이틀·로비·설정)에 이어, 규모가 훨씬 큰
  NPC 상호작용/상점 화면(1500여 줄)을 `OnGUI`에서 런타임 Canvas로 이식
- 원래 140일차에 이벤트 전투까지 같이 하려 했으나 두 화면을 합치면 하루 범위를 크게
  넘어서서(NPC 1528줄 + 이벤트 전투 1383줄), 이벤트 전투는 141일차로, 던전 탐험
  오버레이는 142일차로 하루씩 미뤘다

## 구현 내용

### 1. 화면 구조
- 좌측 열: 일러스트(색상 박스+이름 - 실제 자산 없어 133일차 CG 갤러리와 같은 방식으로
  대체), 호감도/적대 상태 정보, "대화/서비스/선물/공격" 버튼 4개(항상 보임)
- 우측 메인 영역: `serviceScreen` 상태가 바뀔 때마다 `RefreshMainArea()`가 자식을 모두
  지우고 다시 그린다 - OnGUI의 "매 프레임 다시 그리기"를 "상태 변경 시점에 다시
  그리기"로 옮긴 것

### 2. 상점 화면
- 구매/판매 탭, 카테고리 필터(전체/소비/탐험도구/장비/유물) - 선택된 탭/카테고리는
  배경색으로 강조
- 상품·인벤토리 목록은 CG 갤러리(133일차)에서 검증한 `RectMask2D` + `ScrollRect` 조합을
  재사용해 가변 길이 스크롤 목록으로 구성
- 상단에 보유 골드 + 상점 강화 요약(할인율/판매가 보너스) 표시

### 3. 회복 · 정보 · 유물 정리 · 선물 화면
- 회복/정보는 고정 개수 항목이라 계산된 y좌표로 직접 배치
- 유물 정리·선물은 상점과 같은 스크롤 목록 방식 재사용(개수가 가변적이므로)

### 4. 판정 로직은 그대로
- `NpcInteractionService`, `ShopService`, `ShopInteractionService`, `NpcHealingService`,
  `NpcRelicService` 호출부는 전혀 건드리지 않고 그리는 방식만 교체

## 정리
- UI에서 한 번도 쓰인 적 없던 `RescueAffinityGain` 상수(구조 기능이 130일차 UI 개편 때
  버튼에서 빠진 뒤 계속 방치됨)를 이번에 제거

## 남은 사항
- 141일차: 이벤트 전투 화면(1383줄) 정식 UI 전환
- 142일차: 던전 탐험 오버레이(미니맵·문/계단 프롬프트·복귀 HUD·로딩) 정식 UI 전환
