# 9일차: 기본 공격과 승패

---
## 구현 내용

- 기존 명중률, 방어력 감쇠, 95~105% 피해 편차와 최소 피해 규칙 추가.
- 기본 공격, 상대의 기본 공격, 체력 감소와 승패 표시 추가.
- 승리한 방의 시험 조우를 완료하고 패배 시 타이틀 복귀.
- 전투 후 체력을 유지하고 층 이동이 성공했을 때만 기본 최대 체력으로 회복.
- 플레이어와 상대의 공격 결과를 함께 표시.
- 기준: [기존 피해 계산](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/BattleDamageCalculator.cs), [기존 승패 판정](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/BattleOutcomeEvaluator.cs).

---
## 범위

참가자와 적 한 명의 시험 전투다. 적 능력치는 임시값이며 적은 기본 공격으로만 행동한다. `시험 종료`는 개발 확인용으로 기존의 확률 기반 정식 도주가 아니다. 기술·방어 행동·보상·저장과 정식 패배 화면은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 71개와 PlayMode 테스트 37개 통과.
- 명중·빗나감, 승리·패배, 체력 보존·층 이동 회복과 중복 공격 차단 검증.
- 최신 전투 화면 캡처 테스트 1개 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
