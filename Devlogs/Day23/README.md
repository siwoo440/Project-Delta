# Project Delta - 23일차 개발일지

## 개발 주제

**탐험 지도(미니맵) 및 전체 지도 구현**

화면 우측 상단에 현재 방을 보여주는 미니맵과, M키로 여는 확대판 전체 지도를 만들었다. 던전 탐험 구간(11~25일차)의 마지막 항목으로, 22일차까지 코드에 남아있던 `// TODO: 지도 갱신` 자리를 채웠다.

---

## 개발 목표

- 방문한 방 유무와 무관하게, 지금 서 있는 방의 칸·벽·문·콘텐츠 자리를 한눈에 보여주는 미니맵
- 플레이어 위치와 바라보는 방향을 아이콘으로 표시
- M키로 확대된 전체 지도를 열고 Esc로 닫는 최소 기능
- 방-방 연결 그래프가 아직 없는 상태(26~35일차 이전)에서 스코프를 "현재 방 하나"로 명확히 제한

## 구현 내용

### 1. DungeonMinimapController — 미니맵/전체 지도 공통 그리기

```text
DungeonMinimapController (Presentation)
├─ DrawMapPanel() — 미니맵과 전체 지도가 공유하는 실제 그리기 로직
│  ├─ DrawFloorAndWalls() — 방 범위 모든 칸의 바닥 + 사방 벽/문 상태
│  ├─ DrawContentMarkers() — RoomView.GetMarkers()로 조회한 모든 콘텐츠 자리
│  └─ DrawPlayerIcon() — 항상 지도 중심에 고정된 방향 삼각형
├─ OnGUI() — 평소엔 우측 상단 미니맵, M을 누르면 화면 중앙 전체 지도로 전환
└─ Update() — Keyboard.current로 M(열기)/Esc(닫기) 직접 조회
```

플레이어 위치는 항상 지도 중심(중앙 고정)이고, 나머지 칸들이 플레이어 기준 상대 좌표로 그 주위에 그려진다. 벽/문 판정은 새로 만들지 않고 기존 `RoomPassageController.CanPass()`/`TryGetDoor()`를 그대로 조회해서 쓴다 — 판정 로직은 Domain/Presentation 어디에도 중복되지 않는다.

플레이어 방향 아이콘은 이미지 에셋 없이 32×32 텍스처를 코드로 직접 생성한 삼각형이다.

---

### 2. 반복 수정: 크기와 방향 다듬기

오늘 사용자 피드백을 받으며 여러 차례 조정했다.

```text
1차: 미니맵 160px, 삼각형 방향 미확정
↓ "1.5배 키워줘" → 미니맵 240px로 확대
↓ "M으로 전체 지도, Esc로 닫기, 화면 전체가 보이게"
   → DrawMapPanel을 크기 파라미터화해서 미니맵/전체 지도가 같은 로직 공유
↓ "삼각형이 반대 방향" → Texture2D가 (0,0) 좌하단 기준이라 위/아래가 뒤집혀 있던 문제 수정
↓ "전체 지도를 2배 더 키워줘" → 화면을 거의 다 채우도록 fullMapScale 상향 + 화면 밖 넘침 방지 상한(fullMapMaxScreenRatio) 추가
↓ "맵 내용은 원래 크기로, 검은 패널만 크게" → 지도 내용 확대를 되돌리고 패널 크기만 유지
↓ "맵 내용이 너무 작다, 1.5배 키워줘" → fullMapContentScale(1.5배)로 지도 내용만 다시 확대, 패널 크기는 그대로
```

이 과정에서 `DrawEdge`를 여러 크기에서 재사용하도록 고치다가 방 경계 판정이 실수로 `-2/2`로 하드코딩된 걸 발견해서 실제 `minX/maxX/minZ/maxZ` 필드를 쓰도록 바로 잡았다.

---

## 적용 중 발견된 문제 및 수정

1. **삼각형 방향 반전**: `Texture2D.SetPixel`은 `(0,0)`이 좌하단 기준이라, 꼭짓점을 텍스처 데이터의 `y=0`에 둔 첫 버전은 화면에서 오히려 아래쪽에 꼭짓점이 그려졌다. `t` 계산을 뒤집어서(`t = 1f - y/(size-1)`) 꼭짓점이 항상 바라보는 방향(위쪽)에 오도록 고쳤다.
2. **방 경계 판정 하드코딩**: `DrawEdge`를 `static`으로 바꾸는 과정에서 인스턴스 필드(`minX` 등)에 접근할 수 없어 `-2/2`로 임시 하드코딩한 채 남아있었다. 다시 인스턴스 메서드로 돌리고 실제 필드를 참조하도록 수정.

## 최종 확인 항목

23일차 완료 기준은 다음과 같다.

- Unity 컴파일 오류 없음
- 우측 상단에 미니맵이 항상 표시되고, 플레이어가 중심에 고정된 채 방향 삼각형이 정확히 회전함
- 이동 가능한 칸·벽·문(잠김/닫힘/열림 색 구분)·계단 자리가 실제 방 구조와 일치해 보임
- M을 누르면 화면 중앙에 확대된 전체 지도가 뜨고, Esc로 닫힘

**참고**: 방-방 연결 그래프가 없는 상태라 미니맵/전체 지도 모두 "현재 방 하나"만 보여준다. 여러 방을 이어 보여주는 실제 던전 지도는 26~35일차 던전 생성에서 연결 데이터가 생긴 뒤로 미룬다.
