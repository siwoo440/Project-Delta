# 17일차 조우 단계 도망 설계

---
## 목표와 기준

- 사용자가 제공한 기획서의 조우 단계 도망 규칙을 구현한다.
- 플레이어 속도와 1~20 주사위 합이 생존한 가장 빠른 상대 속도와 별도 1~20 주사위 합보다 클 때만 성공한다. 동점은 실패다.
- 성공하면 이전 방으로 돌아가고 몬스터와 조우 기록은 유지한다. 실패하면 일반 전투로 진입한다.
- 이전 방 또는 안전한 도착 칸이 없으면 도망을 실행하지 않고 조우 화면에서 이유를 표시한다.
- 성공 후 도착 방 활성화 중 장애물이 생겨 이동에 실패하면 조우 상태를 보존하고, 이미 성공한 판정으로 이동을 재시도한다.
- 도망 실패 후 전투 화면 생성에 실패해도 도망을 다시 굴릴 수 없도록 하고 전투 재시도를 제공한다.
- 현재 속도와 상대 능력치는 시험값이며, 보정·추가 적·기습 처리는 후속 단계다.

---
## 검증

두 주사위 경계·동점·최고 속도 대상, 실제 이전 방 복귀, 대상 유지, 실패 전투 진입과 이동 실패 복구를 검증한다.
