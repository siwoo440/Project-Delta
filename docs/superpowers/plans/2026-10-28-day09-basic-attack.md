# 9일차 기본 공격과 승패 구현 계획

**목표:** 기존 명중·피해·승패 규칙을 실제 시험 전투와 탐험 복귀에 연결한다.

**구조:** Core에 전투 능력치·체력과 결정 가능한 공격 판정 및 승패 규칙을 둔다. Runtime은 무작위 숫자와 화면·전투 결과를 연결한다.

---
## 순서

1. 명중 상한·하한, 방어 감쇠·피해 편차, 최소 피해와 승패 우선순위의 실패 테스트 작성 후 규칙 구현.
2. 시험 전투의 공격과 적 기본 행동, 체력 표시 및 승패 결과를 연결.
3. 승리 후 조우 완료와 플레이어 체력 보존, 패배 시 복귀 경로를 실제 입력으로 검증.
4. EditMode·PlayMode·최신 화면·Windows 빌드를 별도 프로젝트에서 검증하고 커밋·푸시.

---
## 제한

- 시험 참가자 한 명과 시험 적 한 명만 사용한다.
- 기술, 방어 행동, 전투 보상과 저장은 후속 단계다.
- 기존 씬과 사용자 설정은 보존하고 원래 코드 복사 없이 새로 작성한다.
