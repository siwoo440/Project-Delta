# 75일차 설정과 접근성 시험 설계

---
## 범위

타이틀과 일시정지에서 설정 화면을 열고 닫으면 이전 화면과 입력 선택을 복원한다. 실제 적용 가능한 전체 음량과 조우 전환의 섬광 기본·감소·끔을 제공한다. 각 설정은 변경 직후 회차와 별도 파일에 안전하게 저장하고 재시작 시 적용한다. 저장 실패나 손상된 원본이 있으면 기존 적용값을 유지한다.

---
## 적용 규칙

전체 음량은 0~100의 정수이며 기본값은 100이다. 섬광은 기본·감소·끔을 선택하며 기본값은 기존 연출이다. 섬광을 줄이거나 꺼도 상대 이름과 화면 전환은 유지한다. 키 재설정과 개별 음량, 나머지 접근성 항목은 실제 적용 기반이 없어 미지원으로 구분한다. 현재 E 상호작용과 F 강제 개방, 한 번 누를 때 한 칸 이동 및 게임패드 조작은 유지한다.

---
## 검증

타이틀과 일시정지에서의 열기·닫기, 키보드·게임패드 취소, 음량 실제 적용, 섬광의 실제 화면 전환, 재실행 후 복원, 저장 잠금·손상 시 기존 설정 보호를 검증한다.
