# 70일차 : 5층 탐험과 층 이동 저장 추가

---
## 개발 내용

- 1~5층의 결정적 생성과 기존 1·2층 시드 유지 추가
- 5층의 계단과 상위 개체 방을 마왕 방으로 변경
- 방문한 마왕 방의 미니맵과 전체 지도 표시 추가
- 3~5층 시험 상자·함정·이벤트·상점과 층별 경험치 확장
- 다음 층 도착 상태의 자동 저장과 일반 저장 실패 시 기존 위치 복구 추가
- 5층까지 저장과 재시작 복원 추가
- 최신 실제 5층 플레이 화면 수정

---
## 시험 범위

- 2~4층은 기존 생성 규칙을 사용하고 이전 층으로 돌아갈 수 없다.
- 5층 마왕 전투와 정식 층별 몬스터는 후속 작업이다.
- 층 이동 시 기존 시험 규칙으로 체력만 회복하고 마나는 유지한다. 난이도별 회복은 아직 구현되지 않았다.
- 기존 저장소는 파일 교체 후 최종 재읽기에 실패하면 현재 플레이 위치와 디스크 상태가 달라질 수 있다. 이전 파일의 백업은 보존된다.

---
## 검증

- Unity 6000.3.21f1 EditMode 357개 통과
- 층 이동 자동 저장·잠금 실패 복구 PlayMode 2개 통과
- 1~5층 이동·상점·저장 복원 및 실제 화면 캡처 PlayMode 1개 통과
- 전체 PlayMode 166개 통과
