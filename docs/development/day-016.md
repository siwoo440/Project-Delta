# 16일차: 조우 화면 기반

---
## 구현 내용

- 시험 대상 주변으로 이동하면 바로 전투를 시작하는 대신 조우 선택 화면 표시.
- 조우 화면의 전투 선택으로 기존 턴제 전투에 진입하고 탐험 입력 잠금 유지.
- 조우 화면 또는 전투 화면 생성에 실패하면 이전 상태와 입력을 복구.
- 키보드·게임패드 선택과 누른 입력 유지 시 중복 공격 방지.
- 기준: 사용자가 제공한 기획서의 조우와 전투 흐름.

---
## 범위

현재 조우 화면은 전투 선택만 지원한다. 조우 단계의 도망·회유·유혹·관찰·아이템은 후속 작업이며 대상 그림과 능력치는 시험용이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 103개와 PlayMode 테스트 52개 통과.
- 실제 조우, 키보드·게임패드 전투 선택, 누른 입력과 화면 생성 실패 복구 검증.
- 실제 조우 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
