# 18일차: 조우 관찰 1단계

---
## 구현 내용

- 플레이어 속도·보정과 상대 저항·보정에 각각 1~20 주사위를 더해 관찰 판정하며 동점은 성공.
- 관찰 성공 시 시험 상대의 체력과 기본 공격 성향을 표시하고 같은 회차에서 주사위 없이 다시 확인.
- 관찰 실패 시 일반 전투로 진입하며 화면 생성 실패 시 판정을 보존하고 전투 재시도를 허용.
- 성공한 조우 도망의 이동이 실패한 동안 다른 조우 행동을 차단해 판정 결과를 보존.
- 기준: 사용자가 제공한 기획서의 조우 관찰 규칙.

---
## 범위

관찰 기록은 현재 회차 메모리에만 유지되고 새 게임에서 초기화된다. 정식 영구 도감, 2단계 이후 관찰 정보와 실제 대상 능력치는 후속 작업이다. 속도 10과 저항 10은 시험 수치다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 117개와 PlayMode 테스트 59개 통과.
- 관찰 동점·실패·정보 재확인·새 게임 초기화와 조우 선택 오류 복구 검증.
- 실제 관찰 결과 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
