# 41일차: 회차 탐험 기록 보관

---
## 구현 내용

- 방 진입, 문 상호작용과 회복약 결과를 현재 회차의 시간순 기록에 보관.
- 탐험 화면에는 기존처럼 최근 네 개만 표시하고 오래된 기록은 회차 동안 유지.
- 새 게임 시작 시 이전 회차 기록 초기화.
- 실제 탐험 화면을 README에 갱신.

---
## 범위

기록은 현재 실행 중인 회차의 메모리에 보관한다. 전체 기록 열람 화면과 파일 저장은 아직 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 150개와 PlayMode 테스트 100개 통과.
- 기록 순서, 빈 기록 제외, 최근 네 개 표시와 새 회차 초기화 검증.
- 실제 탐험 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
