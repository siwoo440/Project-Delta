# 30일차: 탐험 체력 표시

---
## 구현 내용

- 던전 화면 왼쪽에 현재 체력과 시험 최대 체력 100 표시.
- 회복과 전투 후 변경된 실제 체력 반영.
- 체력이 25 이하일 때 경고색으로 안내.
- 기존 체력과 아이템 판정 및 입력 유지.
- 최신 실제 플레이 화면을 README에 반영.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 147개와 PlayMode 테스트 95개 통과.
- 체력 변경, 낮은 체력 경고색과 실제 플레이 화면 검증.
- Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
