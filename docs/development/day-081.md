# 81일차 해상도와 전체 회귀 검증

---
## 검증

- Unity 6000.3.21f1 EditMode 420개, PlayMode 195개 통과.
- 실제 휴식 방의 던전 화면을 별도 렌더링 대상으로 1280×720, 1920×1080, 2560×1440에서 캡처하고 화면 구성을 확인.
- 해상도 지정은 자동 검증에만 사용하며 사용자 모니터나 게임 설정은 변경하지 않는다.
- 실제 720p 던전 화면을 README의 최신 플레이 이미지로 확인.

## 미검증 범위

- 자동 캡처는 사람이 실제 모니터에서 수행하는 가독성 평가를 대신하지 않는다.
- 최소 사양 후보 PC의 성능, 장시간 플레이와 내부 시험 완료 조건은 아직 확인되지 않았다.
- 정식 콘텐츠 수량·업적 합계의 기획 불일치와 탐험 정력은 미해결이다.
