# 13일차: 전투 화면 초상화

---
## 구현 내용

- 기획서의 일본 애니메이션풍 선화와 셀 채색에 맞는 성인 주인공·슬라임 퀸 임시 초상화 추가.
- 투명 배경 PNG를 전투 화면에 표시하고 체력, 행동과 결과 표시 영역 확보.
- 창 너비에 따라 초상화 크기를 조절하며 공간이 부족하면 초상화를 숨겨 텍스트 유지.
- 이미지가 없거나 로딩되지 않아도 기존 전투 화면과 버튼을 유지.
- 기준: [프로젝트 δ 기획서](https://docs.google.com/document/d/1xxD2-DW_T5evDsnooiseBg1wJHMi0UdMgrcQ53TsNl4/edit)의 UI·시청각 연출, 2D 캐릭터와 슬라임 퀸 항목.

---
## 범위

이미지는 이미지 생성으로 제작한 개발용 시안이다. 기존 시험 적의 능력치와 행동은 정식 슬라임 퀸 데이터가 아니다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 87개와 PlayMode 테스트 46개 통과.
- 이미지 로드·누락 처리·버튼 입력과 가상 화면 너비별 배치 계산 확인. 실제 창 크기 변경은 실행하지 않음.
- 실제 전투 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
