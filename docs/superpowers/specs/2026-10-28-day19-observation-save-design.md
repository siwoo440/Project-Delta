# 19일차 관찰 기록 영구 저장 설계

---
## 목표와 범위

- 사용자가 제공한 기획서의 관찰 정보 영구 보존과 안전한 저장 원칙에 맞춰 시험 관찰 기록만 저장한다.
- 기존 3D 저장과 분리된 `ProjectDelta2D/observation-v1.json`을 사용하며 이전 저장을 읽거나 변경하지 않는다.
- 새 게임을 시작해도 기록을 유지하고 새 실행에서 다시 불러온다. 정식 도감 전체와 회차 저장은 후속 작업이다.
- 버전·대상 식별자·체크섬을 검증하고 같은 폴더의 고유 임시 파일을 검사한 뒤 원자적으로 현재 파일을 교체한다.
- 기존 정상 파일은 교체 전에 별도 백업으로 보존한다. 자동 백업은 최근 3개를 유지한다.
- 현재 파일이 손상되면 임시 파일과 백업에서 검증 가능한 기록을 읽되 손상된 원본은 변경하지 않으며, 수동 복구 전 추가 저장을 차단하고 안내한다.
- 관찰 저장 실패 시 성공한 판정을 유지해 다시 굴리지 않고 저장을 재시도할 수 있다.
- 테스트는 별도 작업 폴더에서 실행하며 사용자 저장 경로를 사용하지 않는다.

---
## 검증

새 실행과 새 게임의 기록 보존, 버전·체크섬 오류, 기존 파일 보존, 백업 복구, 저장 실패 및 재시도와 기존 게임 입력을 검증한다.
