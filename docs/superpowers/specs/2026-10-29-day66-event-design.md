# 66일차 시험 이벤트 설계

---
## 범위

기존 조우·상자·함정과 겹치지 않는 일반 방에서 회차별 시험 이벤트 하나를 자동 시작한다. 시험 행동과 떠나기의 순서는 회차에 고정하고 재개 시 보존한다. 사용 조건을 충족하지 못하면 행동을 비활성화하고 이유를 표시한다. 취소로 결과 확인을 우회할 수 없다.

---
## 판정과 결과

기존 이벤트 판정의 능력치와 양측 1~20 주사위를 사용하고 동점은 성공으로 처리한다. 400개 조합으로 표시 확률을 계산한다. 조건·난이도·비용·보상과 배치 빈도는 정식 기획이 확인되지 않은 시험값이다. 선택 결과와 비용 및 보상은 사용자에게 표시하기 전에 단일 회차 저장으로 확정한다.

---
## 저장과 복원

이벤트의 층·방·식별자·선택 순서·선택·거래 식별자·비용·주사위·결과·완료 상태를 저장한다. 결과 확인 전 중단해도 같은 결과를 표시하고 재선택과 보상 중복을 막는다. 기존 저장은 호환하며 다른 회차와 기존 콘텐츠를 보존한다.
