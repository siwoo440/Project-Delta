# 5일차: 무작위 1층 던전 생성

---
## 구현 내용

- 새 게임마다 시드 기반의 방 배치와 양방향 출구 생성.
- 일반 방 8~10개와 시작 방·계단 방·상위 개체 방 배치.
- 시작 방에서 계단까지 연결 경로와 지도 좌표 거리를 각각 다섯 칸 이상으로 검증.
- 생성 재시도 제한과 검증된 대체 던전 추가.
- 생성된 구조를 실제 2D 시험 방과 미니맵에 함께 연결.
- 공개된 방만을 기준으로 미니맵 크기와 중심 조절.
- 비활성 방의 문 표시 위치 계산 수정.
- 원본 프로젝트를 Unity에서 열어 둔 상태로 별도 복사본에서 자동 검증.
- 실제 게임 카메라와 UI를 화면 밖에서 렌더링해 README에 반영.

---
## 플레이 범위

계단 방과 상위 개체 방은 역할과 위치만 표시한다. 실제 계단 이동, 상위 개체 조우, 순환 경로, 비밀 방 생성, 잠긴 문과 저장은 이후 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 54개 통과.
- PlayMode 테스트 29개와 게임 화면 캡처 전용 테스트 1개 통과.
- Unity 6000.3.21f1 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 최종 Windows 실행 파일 테스트는 실행하지 않음.
