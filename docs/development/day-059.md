# 59일차: 시험 전투 보상

- 1·2층 일반 적과 상위 개체의 기획 경험치, 연속 레벨 상승 및 스탯 포인트 추가.
- 전투별 보상 후보를 화면 표시 전 저장하고 중단 후 같은 후보를 복원하도록 추가.
- 경험치·시험 골드·시험 회복약과 획득 또는 포기의 거래 기록을 조우 완료와 함께 저장하도록 추가.
- 인벤토리 공간 부족 시 기존 아이템 보존과 명시적 포기 선택 추가.
- 후퇴 전에 제거한 적의 보상 제외와 동일 거래 중복 지급 차단 추가.
- 일시정지 메뉴에 레벨·경험치·골드·스탯 포인트 표시 추가.
- 정식 골드량, 장비·유물 드롭 및 후속 콘텐츠는 미구현.
- 독립 Unity 복사본에서 EditMode 243개, PlayMode 125개와 실제 보상·일시정지 화면 캡처 검증 통과.
