# 65일차 : 시험 상자와 함정 추가

---
## 개발 내용

- 일반 층의 상자와 함정 방 배치 추가
- 열쇠와 강제 판정으로 잠긴 상자 개방 추가
- 등급별 상자 보상과 미믹 확정 후보 저장 추가
- 미믹 조우·전투·후퇴 체력 보존 추가
- 보상 선택과 기존 아이템 교체 확인 추가
- 함정 1회 판정과 회차 상태의 원자적 저장 추가
- 미믹 몬무스 시안과 최신 실제 플레이 화면 추가

---
## 시험 범위

- 층당 상자는 2~3개, 함정은 1개로 배치한다.
- 첫 상자는 일반·미잠금, 두 번째는 고급·잠금, 세 번째는 희귀·미잠금인 시험 배치다.
- 보상은 시험 회복약이며 확률·등급 배치와 함정 피해 10~18은 정식 기획 확정 전 시험값이다.
- 일반·고급·희귀 상자의 미믹 확률은 각각 8%·12%·18%다.
- 상자와 함정 상태, 후보와 체력은 실제 저장 성공 후 적용한다.

---
## 검증

- Unity 6000.3.21f1 EditMode 316개 통과
- 기존 PlayMode 145개 통과
- 상자·미믹·함정의 보완 후 집중 PlayMode 5개 통과
- 별도 프로젝트 복사본에서 실제 상자 화면 캡처
