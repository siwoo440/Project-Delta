# 10일차: 인벤토리 기본 구조

---
## 구현 내용

- 원본과 같은 기본 10칸 인벤토리와 슬롯별 최대 중첩 수량 추가.
- 같은 아이템의 기존 묶음을 먼저 채우고 남은 수량을 빈 슬롯에 배치.
- 공간 부족 시 추가되지 않은 수량을 반환하고 기존 아이템 보존.
- 키보드·게임패드 인벤토리 열기와 닫기, 시험 아이템 획득 화면 추가.
- 열린 화면에서 탐험 입력을 잠그고, 층 이동 시 인벤토리 유지와 새 게임 초기화.
- 기준: [기존 인벤토리 규칙](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Domain/RunSubStates.cs).

---
## 범위

화면의 시험 아이템 획득은 개발 확인용이다. 정식 드롭·상자·아이템 사용·장비·저장과 인벤토리 확장은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 77개와 PlayMode 테스트 42개 통과.
- 키보드·게임패드의 열기·닫기, 누른 입력 유지와 이동 중 잠금 검증.
- 최신 인벤토리 화면 캡처 테스트 1개 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
