# 25일차: 일반 전투 회복약 사용

---
## 구현 내용

- 시험 소형 회복약을 일반 전투의 플레이어 행동으로 사용하도록 연결.
- 회복에 성공하면 체력과 아이템 수량을 갱신하고 플레이어 행동을 소모해 상대 행동 진행.
- 체력이 최대이거나 회복약이 없으면 기존 체력·아이템·행동을 보존.
- 전투 종료 후 회복약 사용을 차단하고 키보드·게임패드 선택 제공.

---
## 범위

현재 전투 회복약은 시험 소형 회복약 한 종류다. 정식 아이템 선택 목록과 다른 종류의 아이템은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 143개와 PlayMode 테스트 87개 통과.
- 회복 성공 시 아이템과 행동 소비, 상대 행동 및 전투 체력 동기화 검증.
- 최대 체력·아이템 부재 시 행동 보존, 키보드·게임패드 사용과 종료 후 차단 검증.
- 실제 전투 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
