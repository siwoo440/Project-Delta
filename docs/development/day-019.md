# 19일차: 관찰 기록 영구 저장

---
## 구현 내용

- 1단계 관찰 대상을 2D 전용 저장 폴더에 보관해 새 게임과 게임 재시작 후에도 유지.
- 체크섬으로 저장 내용을 검증하고 임시 파일, 원자적 교체와 최근 정상 백업으로 기존 기록 보호.
- 손상이나 다른 실행의 변경을 발견하면 원본을 보존하고 자동 덮어쓰기를 차단.
- 저장 실패 시 원인을 표시하고 실행 중 조우를 다시 열어도 성공 판정을 재사용.
- 재시작할 때 저장하지 못한 관찰 판정이 초기화된다는 안내 추가.
- 기준: 사용자가 제공한 기획서의 영구 관찰 기록.

---
## 범위와 복구

관찰 대상 식별자만 저장하며 전체 게임 진행 저장과 정식 도감은 후속 작업이다. 손상된 원본이 있으면 유효한 복구 파일을 읽기 전용으로 표시하고, 원본을 확인하기 전까지 새 저장을 차단한다. 저장 오류나 충돌 시 표시된 안내를 확인해야 한다. 검증은 실제 사용자 저장과 분리된 시험 폴더를 사용한다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 125개와 최종 PlayMode 테스트 61개 통과.
- 새 게임과 재초기화 후 관찰 기록 유지, 손상 파일 보호와 최신 복구 후보 검증.
- 저장 실패 후 재조우 재시도, 외부 변경 충돌과 재시작 안내 검증.
- 실제 관찰 결과 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
