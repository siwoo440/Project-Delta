# 51일차 조우 데이터 설계

기획서의 1~2층 시험 범위에 맞춰 슬라임, 고블린, 각 층의 상위 개체를 ID와 등장 층으로 정의한다. 한 조우는 최대 세 개체이며 일반 개체의 같은 종족 중복을 허용한다. 첫 몬스터 조우는 슬라임으로 검증하며 첫 조우의 개체 수는 확정하지 않는다. 상위 방에는 해당 층의 상위 개체를 포함하며 일반 개체와 함께 배치할 수 있다. 일반 조우는 일반 방에 고정한다. 확정되지 않은 배치 확률과 전투 수치는 임의로 정하지 않는다.

이번 작업은 조우 정의와 방 배치의 Core 기반이다. 화면의 기존 시험 상위 개체와 실제 일반 몬스터 조우·전투 연결은 다음 작업 범위다. 비밀방, 시작 방과 계단 방에는 일반 조우를 배치하지 않는다.
