# 69일차 : 시험 이벤트 전투와 저장 복원 추가

---
## 개발 내용

- 일반 전투 생존 적의 개별 슬롯과 체력을 별도 전투로 전달 추가
- 대상 선택·관찰·세 가지 시험 행동과 정력·진행 게이지 추가
- 양측 주사위의 주도권 판정과 동점 유지 추가
- 모든 적 제거 승리와 정력 소진 패배 기록 추가
- 일반 처치 100%와 이벤트 전투 참가자 80% 경험치 합산 추가
- 완료 행동별 회차 저장과 재실행 후 주도권 복원 추가
- 시험 전투 중단 확인과 이전 방 저장·복귀 추가
- 최신 실제 플레이 화면 갱신

---
## 시험 범위

- 시험 정력 100, 매력 50, 세 행동의 진행량 10·20·30과 정력 비용 3·5·8은 정식 확정 전 시험값이다.
- 관찰은 해당 대상의 현재 체력과 시험 매력을 보여주며 영구 관찰 도감과는 연결되지 않는다.
- 시험 중단은 보상을 포기하고 이전 방으로 돌아가며 정식 후퇴 확률 판정이 아니다.
- 미믹은 상자 보상 연동이 아직 없어 이벤트 전투 진입을 차단한다.
- 이벤트 전투 승리는 현재 경험치만 지급하며 정식 아이템·골드 보상은 후속 작업이다.
- 재생 검증의 행동 기록은 256개까지 보관하며 한도 도달 시 시험 중단을 사용할 수 있다.

---
## 검증

- Unity 6000.3.21f1 EditMode 346개 통과
- 최종 상대 화면 정렬 전 전체 PlayMode 163개 통과
- 이벤트 전투 집중 PlayMode 7개 통과 및 최종 화면 캡처 테스트 1개 통과
- 전체 테스트 중 유물 연속 획득 실패가 한 차례 발생했으나 원인은 확인되지 않았고, 단계별 저장 검증을 보강한 재실행에서는 통과했다.
