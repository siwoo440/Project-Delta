# 7일차: 자동 조우와 전투 화면

---
## 구현 내용

- 상위 개체 방에 시험 대상을 배치하고 주변 8방향 한 칸 도착 시 자동 조우.
- 전투 화면에서 탐험 입력을 잠그고 시험 종료 시 기존 층·방·위치와 발견 기록 복구.
- 연속 입력 중 첫 포착 칸에서 조우하고 대기 이동 취소.
- 원본 프로젝트의 조우 거리 규칙과 전투 화면 전환 흐름을 기준으로 새 코드 작성.
- 기준: [기존 조우 범위 규칙](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/EncounterRangeRule.cs).
- 최신 전투 화면을 화면 밖에서 렌더링해 README 갱신.

---
## 범위

전투 화면은 진입과 복귀를 확인하는 시험 화면이다. 실제 턴·행동·승패 규칙은 기존 프로젝트를 기준으로 후속 구현한다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 63개, PlayMode 테스트 34개 통과.
- 실제 전투 화면 캡처 테스트 1개 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
