# 64일차 : 시험 상점과 유물 경제 추가

---
## 개발 내용

- 유물 별도 보유 한도 5개와 중복 방지, 확인 후 교체 추가
- 시험 유물의 공격·방어·속도 효과를 실제 전투에 반영
- 층별 시험 상점 상품과 확정 가격·재고 저장 추가
- 구매·판매와 골드·인벤토리·재고의 원자적 저장 추가
- 잔액·공간 부족과 저장 충돌 시 거래 원상 보존 추가
- 상점 화면과 이전 회차의 빈 유물·상점 복원 추가
- 최신 실제 플레이 화면 갱신

---
## 시험 범위

- 상점 방과 NPC는 후속 작업이며 인벤토리의 시험 상점 버튼으로 접근한다.
- 판매는 현재 상점에 같은 상품이 있는 아이템만 지원하고 판매가는 구매가의 50%를 버린다. 개별 옵션 장비 판매가는 미정이다.
- 유물 버튼은 개발 확인용 무료 지급이며 상품 구성·재고·유물 효과와 판매 반올림은 시험값이다.
- 판매한 아이템은 현재 시험 상점 재고에 추가되지 않는다.

---
## 검증

- Unity 6000.3.21f1 EditMode 298개 통과
- 상점 거래, 실패 보존, 층별 상점과 유물 교체 집중 PlayMode 4개 통과
- 전체 PlayMode 145개 통과
