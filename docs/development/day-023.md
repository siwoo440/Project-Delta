# 23일차: 가득 찬 인벤토리 획득 선택

---
## 구현 내용

- 시험 아이템을 받을 공간이 없을 때 두고 가기 또는 기존 아이템 교체 선택 제공.
- 교체할 슬롯의 이름과 수량을 보여 주고 최종 확인 전까지 기존 묶음 보존.
- 교체 취소 시 획득 선택으로 돌아가고, 확인 중 대상이 바뀌면 덮어쓰기 차단.
- 가득 참 선택 중 아래 인벤토리 입력 잠금과 키보드·게임패드 조작 지원.
- 현재 기획서의 두고 가기·교체·취소 및 버리기 확인 원칙 반영.

---
## 범위

현재 기능은 개발 확인용 시험 아이템 획득에 적용된다. 정식 전리품·상자와 회차 저장은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 134개와 PlayMode 테스트 79개 통과.
- 가득 찼을 때 두고 가기, 교체 취소와 최종 확인 후 획득 검증.
- 확인 중 대상 변경 보호, 기존 이동 표시 정리 및 게임패드 조작 검증.
- 실제 교체 확인 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
