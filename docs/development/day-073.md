# 73일차 : 내부 시험 파편 상태와 성장 규칙 추가

---
## 개발 내용

- 기획서의 영구 능력치·슬롯·상점·탐험·시작 보너스 성장 비용과 효과 조회 추가
- 타이틀에 결말 최초 해금 파편의 누적 획득량 표시 추가
- 결말 저장 손상 시 파편 확인 불가와 원본 보존 안내 추가
- 내부 시험의 파편 사용 불가 표시 추가
- 최신 실제 플레이 화면과 파편 상태 화면 수정

---
## 시험 범위

- 현재 내부 시험에서는 파편 구매·소비와 영구 성장의 새 회차 적용을 제공하지 않는다.
- 표시 수치는 결말 최초 해금 보상의 누적 획득량이며 전체 파편 잔액이 아니다.
- 난이도별 층 돌파·회차 완료 파편 및 미구현 기술 해금은 반영하지 않았다.
- 성장 규칙의 수치는 기획서의 현재 표를 사용하며 실제 구매·효과 적용 검증은 후속 작업이다.

---
## 검증

- Unity 6000.3.21f1 전체 EditMode 410개 통과
- 실제 마왕전·영웅 귀환 후 파편 표시, 재시작 보존, 손상 기록 보호 PlayMode 2개 통과
- 실제 타이틀 파편 상태 화면과 실제 결말 선택 화면 캡처 테스트 각각 1개 통과
- 전체 PlayMode 176개 통과
