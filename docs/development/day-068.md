# 68일차 : 시험 NPC 관계와 영구 저장 추가

---
## 개발 내용

- 고유 NPC별 0~100 호감도와 관계 단계 추가
- 시험 상인 대화에 관계 수치·단계 표시 추가
- 회차당 한 번의 시험 우호 선택과 실제 변화량 안내 추가
- 영구 관계와 회차별 적용 기록의 단일 저장 추가
- 저장 충돌·손상·복구 시 기존 관계 파일 보호 추가
- 재시작과 새 회차 관계 복원 및 중복 반영 차단 추가
- 최신 실제 플레이 화면 갱신

---
## 시험 범위

- 시험 우호 선택의 증가량 5와 회차당 한 번 제한은 정식 수치 확정 전 시험값이다.
- 기본 대화와 거래는 호감도를 변경하지 않는다.
- 100의 엔딩 가능 단계는 실제 엔딩이나 선행 조건 완료를 뜻하지 않는다.
- 관계 이벤트·선물·정식 선택지는 후속 작업이다.

---
## 검증

- Unity 6000.3.21f1 EditMode 336개 통과
- 마지막 관계 오류 안내 수정 전 전체 PlayMode 155개 통과
- 최종 관계 안내·손상 보호 집중 PlayMode 3개 통과
- 별도 프로젝트 복사본에서 실제 상인 관계 화면 캡처
