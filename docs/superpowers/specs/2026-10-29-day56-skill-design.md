# 56일차 시험 전투 기술 설계

---
## 기능 범위

- 최신 기획의 기본 마나 50과 시험 기술 강한 일격을 실제 일반 전투에 연결한다.
- 강한 일격은 마나 10, 공격 보정 +10, 치명타 40%, 맨손 배율 1.5배, 대기 1턴의 기획 시험값을 사용한다.
- 대기 1턴은 사용 뒤 다음 자신의 행동 차례에는 사용할 수 없고 그다음 차례 시작에 해제한다.
- 마나 부족과 대기 중 사용은 현재 자원과 행동을 보존한다.
- 시작 기술 선택, 반격 태세와 집중 호흡, 장착 무기의 치명타 배율은 후속 작업이다.

---
## 저장과 검증

- 현재 마나는 회차 저장에 포함하며 기존 저장은 기본 마나 50으로 읽는다.
- 기술 비용·대기·명중·치명타·저장 재개와 기존 전투 회귀를 검증한다.
