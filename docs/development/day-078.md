# 78일차 시험 휴식 방

---
## 구현

- 기존 콘텐츠와 분리된 층별 휴식 공간과 사용·보류 선택 추가.
- 체력과 마나를 각각 최대치의 30% 회복하고 사용 완료·탐험 기록을 회차와 함께 저장.
- 저장 실패 시 수치와 미사용 상태를 보존하고 다시 시도할 수 있도록 처리.
- 새 회차에서 휴식을 상인보다 먼저 배치하고 잠긴 말단을 제외하며 이전 저장의 배치 순서 유지.
- 상인과 휴식 지점의 상호작용보다 정면 문 이동을 우선.

---
## 현재 제한

- 탐험 정력이 아직 없어 정력 회복은 지원하지 않는다.
- 기존 조우·상자·함정·이벤트·잠긴 방을 보존하면 1층 시드 1,002개 중 25개에서 접근 가능한 휴식 방을 배치하지 못한다. 1층 휴식 보장에는 콘텐츠 생성 규칙 보완이 필요하다.
- 휴식 우선 배치 후 상인을 배치할 빈 방이 없으면 해당 층의 시험 상인이 생략될 수 있다.

---
## 검증

- Unity 6000.3.21f1 EditMode 419개 통과.
- 전체 PlayMode 192개 중 191개 통과. 남은 1개는 이전 관찰 버튼 기대값으로 실패했으며 테스트 수정 후 해당 검사 1개 통과.
- 실제 휴식의 보류·저장 실패·재시도·회복·기록·재시작·중복 방지 검사 통과.
- 버전 20 회차 재개와 기존 상인 순서, 다섯 층 이동·상인 검증 통과.
- 실제 휴식 선택 화면 캡처 테스트 통과.
