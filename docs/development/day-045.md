# 45일차: 회차 저장 복구

- 현재 파일이 손상되거나 누락되면 백업·임시 파일을 최신 저장 시도 순으로 검증하여 읽기 복구.
- 복구 중에는 손상 원본과 후보를 보존하고 추가 저장 차단.
- 이전 백업 이름 및 새 임시 파일 이름의 시각 정렬 지원.
- 타이틀의 복구 안내와 복구된 회차 이어하기 검증.
- 정상 현재 파일이 있으면 확인된 현재 파일을 우선하며, 파일을 직접 교체하는 복구 도구는 후속 작업.
- 백업 이름 호환성 수정 전 PlayMode 106개 통과. 수정 후 EditMode 170개와 복구 재개 PlayMode 1개 및 실제 플레이 화면 캡처 1개 통과.
