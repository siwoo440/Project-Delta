# 27일차 던전 타일과 방 전환 설계

---
## 범위

- 생성한 일본 애니메이션풍 바닥, 장애물, 문 이미지를 실행 중 시험 던전에 적용한다.
- 기존 격자 좌표와 충돌 판정은 유지하고 각 타일의 월드 가로·세로 표시 크기를 두 배로 늘린다.
- 플레이어 크기도 가로·세로 두 배로 늘리고 각 바닥 칸에 검은 테두리를 표시한다.
- 카메라가 방의 범위를 고려해 플레이어를 따라가며 방 가장자리의 빈 화면을 제한한다.
- 문을 통해 방을 이동하거나 전투 후퇴로 이전 방에 돌아올 때 도착 화면이 부드럽게 이동한다.
- 전환 중에는 추가 이동과 문 상호작용을 차단하고, 실패한 방 이동에서는 전환 효과를 시작하지 않는다.
- 기존 씬·사용자 지정 타일을 파일에 덮어쓰지 않고 실행 중 확인된 시험 타일만 교체한다.

---
## 검증

두 배의 칸 간격, 이미지 연결, 플레이어 중심 카메라, 부드러운 전환과 전환 중 입력 차단, 문·장애물·층 이동과 기존 전투 회귀를 검증한다.
