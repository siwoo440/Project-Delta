# 135일차 : 입력 버퍼 및 상태 다중 신호 표시 구현

## 목표
- 기획서 8.1절 "UI·그래픽 기본 방향" 중 두 가지 구체 요구사항 구현
  - 이동 중 대기 행동 최대 1개(입력 버퍼)
  - "색상만으로 구분하지 않는다" - 색+아이콘+텍스트 3중 신호

## 구현 내용

### 1. 입력 버퍼 (이동 중 대기 행동 최대 1개)
- `PlayerGridMovementController.TryMove()` - 기존엔 이동 중(`isMoving`)이면 입력을 그냥
  버렸다. 이제는 `pendingInput` 필드 하나에 마지막 입력만 저장해뒀다가
  `MoveRoutine()` 종료 직후 곧바로 실행한다(여러 번 눌러도 최신 입력 1개만 남음)
- 입력 잠금 상태(`IsInputLocked`, NPC 대화·전투 진입 등)에서는 대기 입력을 비운다 -
  잠금이 풀린 뒤 예전 입력이 갑자기 실행되는 것을 막는다

### 2. 상태 다중 신호 표시
- `BattleParticipantSlotView.Bind()` - 전투 참가자 생존/전사 여부를 그동안
  `portraitImage`의 틴트 색상 하나로만 표시했다. 이번에 이름 텍스트에 기호+텍스트
  ("☠ {이름} (전사)")를 더해 색+아이콘+텍스트 3중 신호로 만들었다
- 기존 프리팹 구조를 바꾸지 않고 이미 있던 `nameText` 필드만 활용해서 에디터 작업 없이
  코드만으로 반영됨(장비 희귀도는 이미 `EquipmentRarityRules.GetDisplayName`으로
  텍스트 라벨이 있어 그대로 두었다)

## 남은 사항
- 미니맵 등 색상 단독으로 남아있는 다른 표시들은 8.2절 화면별 정식 UI 전환 때 순서대로 정리
