# 10일차 인벤토리 기본 구조 구현 계획

**목표:** 원본의 기본 10칸과 아이템 중첩 규칙을 탐험 화면에서 확인한다.

**구조:** Core에 슬롯·획득 수량 규칙을, Runtime에 탐험 상태별 화면과 입력 연결을 둔다.

---
## 순서

1. 기본 칸 수, 기존 중첩 우선, 빈 칸 분배, 부족 수량과 잘못된 입력의 실패 테스트 작성 후 규칙 구현.
2. 인벤토리 열기·닫기와 시험 아이템 획득 화면 구현.
3. 실제 키보드·게임패드 입력, 탐험 위치 보존, 층 이동 유지와 새 게임 초기화 검증.
4. 별도 Unity 프로젝트에서 전체 테스트, 최신 화면 캡처와 Windows 빌드를 확인한 뒤 커밋·푸시.

---
## 제한

- 시험 아이템 획득은 개발 확인용으로 명시한다.
- 정식 아이템 사용, 드롭, 상자와 저장은 이 범위에서 제외한다.
- 기존 씬과 사용자 설정, 사용자 화면과 입력 장치를 보존한다.
