# 16일차 조우 화면 기반 설계

---
## 목표와 기준

- 사용자가 제공한 기획서의 조우 선택 화면과 별도 턴제 전투 흐름을 기준으로 한다.
- 시험 대상 근처에 도착하면 탐험 입력을 잠그고 조우 화면을 표시한다.
- 실제 전투 선택에만 기존 시험 전투 화면으로 이동한다. 전투 결과의 탐험 복귀와 완료된 조우 기록은 유지한다.
- 조우 화면과 전투 화면 생성 실패 시 이전 상태와 입력을 복구한다.
- 도망·회유·유혹·관찰·아이템은 아직 동작을 만들지 않으며 안내에 후속 기능임을 밝힌다.
- 시험 조우 이미지와 능력치는 임시값이며 정식 슬라임 퀸 데이터로 취급하지 않는다.

---
## 검증

상태 전환과 중복 요청, 실제 조우 시 입력 잠금, 키보드·게임패드 전투 선택과 기존 승패·도주·탐험 복귀를 검증한다.
