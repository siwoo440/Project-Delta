# 54일차 탐험 화면과 일시정지 메뉴 설계

---
## 화면 구성

- 탐험 화면의 현재 체력을 하단 상태 영역에 배치하고 기존 하단 조작 설명은 제거한다.
- 기존 회차 기록·저장 버튼을 탐험 화면에서 제거한다.
- 미니맵을 클릭하면 전체 지도를 열고 별도의 전체 지도 버튼은 제거한다.
- 상단 던전 정보의 높이를 줄이고 오른쪽 하단에 주인공 일러스트를 표시한다.
- WASD를 한 방향으로 누르고 있으면 장애물과 경계 판정을 유지하며 연속 이동한다.
- Esc 또는 게임패드 취소 입력으로 탐험을 잠그고 왼쪽 메뉴와 오른쪽 현재 회차 기록을 표시한다.
- 메뉴는 계속하기·저장·불러오기·타이틀 복귀를 제공하며 회차 기록은 페이지로 탐색한다.

---
## 저장과 불러오기

- 저장은 기존 검증·충돌·손상 보호 경로를 사용한다.
- 불러오기는 저장된 회차의 검증을 거쳐 던전 씬을 재구성한다.
- 이동 또는 방 전환 중인 상태에서는 메뉴 진입을 차단한다.

---
## 검증

- 키보드와 실제 버튼으로 메뉴 진입·닫기, 탐험 잠금, 저장·불러오기를 검증한다.
- 기록과 하단 체력 표시 및 설명 제거를 실제 화면에서 확인한다.
- 실제 미니맵 클릭과 키 누름 유지·장애물 차단을 검증한다.
