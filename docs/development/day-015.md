# 15일차: 전투 방어 행동

---
## 구현 내용

- 방어 행동을 선택하면 한 턴을 사용하고 다음 자신의 행동 차례까지 방어 가능한 직접 피해 감소.
- 기존 규칙에 따라 감소율 30% + 방어력 × 30 ÷ (방어력 + 100), 최대 60% 적용.
- 기본 피해와 편차 계산 뒤 감소율을 적용하고 최소 피해 1 유지.
- 전투 화면에 방어 버튼과 결과 안내를 추가하고, 창 너비에 맞춰 행동 버튼 배치.
- 기준: 사용자가 제공한 기획서의 일반 전투 방어와 기존 피해 계산 코드.

---
## 범위

현재 시험 전투의 기본 공격에 방어를 적용한다. 방어 관통·방어 불가 기술과 능력치 강화·약화는 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 102개와 PlayMode 테스트 50개 통과.
- 방어력별 감소율, 피해·최소 피해·상태 종료와 키보드·게임패드 선택 검증.
- 가상 화면 너비를 이용해 버튼 배치를 확인했으며 실제 창 크기 변경은 실행하지 않음.
- 실제 전투 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
