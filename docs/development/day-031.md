# 31일차: 미니맵 표시 범위 개선

---
## 구현 내용

- 기획서에 맞춰 현재 방 중심의 5×5 범위만 미니맵에 표시.
- 범위 밖의 방과 연결선을 표시하지 않고 방 이동 시 현재 방을 지도 중심으로 갱신.
- 기존 방문·연결 공개 및 미발견 비밀 방 보호 유지.
- 최신 실제 플레이 화면을 README에 반영.

---
## 범위

전체 지도, 계단·NPC·보물 아이콘과 지도 구매 표시는 아직 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 148개와 PlayMode 테스트 95개 통과.
- 5×5 경계, 좌표 범위와 실제 방 이동 후 지도 중심 검증.
- 실제 플레이 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
