# 66일차 : 시험 이벤트와 결과 저장 추가

---
## 개발 내용

- 기존 조우·상자·함정과 분리된 시험 이벤트 방 배치 추가
- 방 진입 시 선택 화면 자동 표시와 선택 순서 저장 추가
- 골드 조건의 비활성화와 정확한 주사위 성공률 표시 추가
- 이벤트 비용·판정·보상과 고유 거래의 원자적 저장 추가
- 결과 확인 화면과 중단 후 동일 결과 복원 추가
- 같은 회차에서 동일 이벤트의 중복 발생 차단 추가
- 이벤트 선택 화면의 최신 실제 플레이 화면 갱신

---
## 시험 범위

- 이벤트 내용은 수상한 장치 조사 한 종류이며 행동과 떠나기 중 선택한다.
- 행동 비용 10골드, 난이도 50, 성공 보상 20골드는 정식 수치가 아닌 시험값이다.
- 장비 보정을 제외한 공격력 50과 두 주사위를 사용하고 동점은 성공이다.
- 정식 이벤트와 NPC 연결은 후속 작업이다.

---
## 검증

- Unity 6000.3.21f1 EditMode 325개 통과
- 마지막 저장 위치 검증 전 전체 PlayMode 152개 통과
- 최종 이벤트 화면과 저장 위치 검증 후 집중 PlayMode 2개 통과
- 별도 프로젝트 복사본에서 실제 이벤트 화면 캡처
