# 28일차: SD 주인공 이미지

---
## 구현 내용

- 기획서의 주인공을 19세 대학생으로 수정하고 SD 스타일 필드 표현을 반영.
- 장비 없는 주인공의 일본 애니메이션풍 투명 이미지를 제작해 시험용 플레이어에 적용.
- 두 배로 커진 타일에 맞춰 주인공 크기를 조정하고 방향 화살표를 축소해 아래에 배치.
- 기존 시험용 이미지가 아닌 사용자 지정 플레이어 이미지는 그대로 보존.
- 실제 던전 화면을 캡처해 README에 갱신.

---
## 범위

현재 주인공은 한 장의 SD 이미지로 표시되며 이동 방향은 별도 화살표로 안내한다. 방향별 스프라이트와 이동 애니메이션은 아직 적용하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 147개와 PlayMode 테스트 93개 통과.
- 캐릭터 이미지·크기·방향 표시와 사용자 이미지 보존 확인.
- 실제 방 이동 후 플레이 화면 캡처 테스트 및 Windows 빌드 성공.
- 사용자 화면 보호를 위해 Windows 실행 파일 테스트는 실행하지 않음.
