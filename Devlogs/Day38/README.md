# Project Delta - 38일차 개발일지

## 개발 주제

**전체 지도 중앙 정렬·연결선·확대/축소·탐험 정보 구현**

37일차에서 `GeneratedDungeon` 기반 미니맵과 Fog of War 방식의 탐색 공개 시스템을 구현했다.

38일차에서는 M키로 여는 전체 지도를 실제 탐색용 상세 지도 형태로 확장하고, 발견된 방 기준 중앙 정렬, 방 연결선, 마우스 휠 확대/축소, 탐험률, 계단 거리, 층 진행도 정보를 추가했다.

---

## 개발 목표

- 37일차 우측 상단 미니맵 유지
- 전체 지도에서 발견된 방 영역 기준 중앙 정렬
- 발견된 방끼리 실제 그래프 연결선 표시
- 미발견 방과 연결선은 계속 숨김
- 마우스 휠 기반 전체 지도 확대/축소
- 방문한 방 기준 탐험률 계산
- 현재 방에서 계단 방까지 그래프 최단 거리 계산
- 계단 미발견 시 거리 정보 숨김
- 현재 층 / 전체 층 진행도 표시
- 전체 지도 계산 로직 EditMode 테스트 추가

## 1. DungeonMapAnalytics 추가

전체 지도 표시에서 필요한 계산을 `DungeonMinimapController`에 직접 모두 넣지 않고 도메인 계산 클래스로 분리했다.

추가된 주요 데이터:

```text
DungeonMapProgress
DungeonMapBounds
DungeonMapConnection
DungeonMapAnalytics
```

`DungeonMapAnalytics`는 다음 기능을 담당한다.

```text
탐험률 계산
발견된 방 영역 Bounds 계산
표시 가능한 방 연결 목록 계산
현재 방 → 목표 방 최단 거리 계산
```

---

## 2. 발견 영역 기준 전체 지도 중앙 정렬

37일차 미니맵은 현재 방을 항상 화면 중앙에 두는 구조를 유지한다.

38일차 전체 지도는 현재 방이 아니라 **현재까지 발견한 전체 방 영역의 중심**을 기준으로 배치한다.

```text
발견된 Room 좌표
↓
MinX / MaxX / MinZ / MaxZ 계산
↓
Bounds 중심 좌표 계산
↓
전체 지도 패널 중앙에 배치
```

아직 발견하지 않은 방은 Bounds 계산에서도 제외한다.

따라서 숨겨진 먼 방 때문에 전체 지도가 불필요하게 작아지거나, 플레이어가 전체 던전 크기를 미리 추측하는 것을 방지한다.

---

## 3. 방 연결선 표시

`RoomNode.Connections`를 읽어 실제로 연결된 방 사이에 선을 표시한다.

```text
□ ─ □

□
│
□
```

양쪽 방이 모두 발견된 경우에만 연결선을 생성한다.

미발견 방으로 이어지는 연결은 지도에 표시하지 않는다.

또한 양방향 그래프에서 같은 연결이 두 번 그려지지 않도록 방 ID 쌍을 기준으로 중복 연결을 제거한다.

---

## 4. 전체 지도 확대 / 축소

전체 지도가 열린 상태에서 마우스 휠로 배율을 조절할 수 있도록 구현했다.

기본 설정:

```text
최소 배율 : 0.6x
기본 배율 : 1.0x
최대 배율 : 2.0x
배율 단계 : 0.2
```

확대/축소 시 다음 요소가 함께 조정된다.

```text
방 사이 간격
방 아이콘 크기
플레이어 방향 아이콘
연결선 두께
```

전체 지도 하단에는 현재 줌 배율과 조작 안내를 표시한다.

```text
마우스 휠 : 확대/축소
M / Esc : 닫기
```

---

## 5. 탐험률 계산

현재 층의 전체 생성 방을 기준으로 실제 탐험한 방 수를 계산한다.

탐험 완료로 취급하는 상태:

```text
Visited
Current
```

미방문 방은 발견되어 지도에 보여도 탐험 완료 수에는 포함하지 않는다.

표시 예:

```text
탐험률 : 4 / 8 (50%)
```

---

## 6. 계단 거리 계산

현재 방에서 `GeneratedDungeon.StairsRoom`까지의 최단 거리를 BFS 방식으로 계산한다.

```text
현재 RoomNode
↓
연결 그래프 BFS
↓
StairsRoom
↓
통과해야 하는 연결 수 계산
```

예:

```text
현재 방 → 방 A → 방 B → 계단 방
계단 거리 : 3방
```

현재 방이 계단 방이면 거리는 `0방`이다.

---

## 7. 계단 정보 Fog of War 유지

37일차 탐색 규칙을 유지하기 위해 계단 방을 아직 발견하지 않은 상태에서는 실제 거리를 표시하지 않는다.

```text
계단 미발견
→ 계단 거리 : ?

계단 발견
→ 계단 거리 : N방
```

따라서 전체 지도 기능을 사용해도 숨겨진 계단 위치를 미리 파악할 수 없다.

---

## 8. 층 진행도 표시

전체 지도 상단에 현재 층 정보를 표시한다.

기본 전체 층 수는 현재 `5`로 설정되어 있다.

표시 예:

```text
층 진행도 : 1 / 5
```

현재 층 번호는 기존 `DungeonRunState.CurrentFloor`을 사용한다.

---

## 9. 전체 지도 정보 영역 구성

M키로 전체 지도를 열면 상단 정보 영역에 다음 내용을 표시한다.

```text
층 진행도
탐험률
계단 거리
```

중앙:

```text
발견된 던전 그래프
방 아이콘
방 연결선
플레이어 위치 및 방향
```

하단:

```text
마우스 휠 확대/축소 안내
현재 줌 배율
M / Esc 닫기 안내
```

---

## 10. 기존 37일차 미니맵 유지

전체 지도 기능을 확장하면서도 기존 우측 상단 미니맵 동작은 유지한다.

```text
평상시
→ 현재 방 중심 미니맵

M
→ 발견 영역 중심 전체 지도

M 또는 Esc
→ 전체 지도 닫기
```

37일차의 다음 규칙도 그대로 유지한다.

```text
현재 방 주변 8칸 공개
미발견 방 숨김
한 번 발견한 방 계속 표시
새 층에서 발견 상태 초기화
```

## 11. EditMode 테스트 추가

`DungeonMapAnalyticsTests`를 추가해 전체 지도 계산 규칙을 검증하도록 구성했다.

테스트 항목:

```text
Visited + Current 방의 탐험률 계산
미발견 방을 제외한 Bounds 계산
미발견 방으로 이어지는 연결선 제외
현재 방 → 계단 방 그래프 최단 거리 계산
현재 방이 목표 방일 때 거리 0 처리
```

총 5개의 EditMode 테스트가 추가되었다.
