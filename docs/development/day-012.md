# 12일차: 전투 도주

---
## 구현 내용

- 기존 임시 도주 공식인 50% + 행동자 속도 - 생존 상대 평균 속도를 적용하고 5~95%로 제한.
- 0~99 난수가 성공률보다 작을 때 성공하며, 성공 시 보상 없이 조우를 완료하고 탐험으로 복귀.
- 실패 시 행동을 소모하고 남은 적 행동과 다음 라운드 진행.
- 실제 도주 버튼과 실패 안내를 추가하고 시험 종료 기능과 구분.
- 기준: [기존 도주 확률](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/BattleEscapeCalculator.cs), [기존 조우 결과](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/EncounterResult.cs).

---
## 범위

기존 프로젝트에서 도주 공식은 임시 수치다. 강화·약화와 상태 이상은 현재 적용되지 않으며 시험 참가자의 속도를 사용한다. 시험 종료는 정식 도주와 별도의 개발 확인용 기능이다.

---
## 검증 결과

- 별도 Unity 프로젝트의 EditMode 테스트 87개와 PlayMode 테스트 45개 통과.
- 도주 확률·난수 경계, 실제 키보드 선택, 성공·실패와 기존 전투 회귀 검증.
- 실제 전투 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
