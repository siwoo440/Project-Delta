# 35일차: 게임패드 지도 입력

---
## 구현 내용

- 게임패드 보기 버튼으로 전체 지도 열기와 닫기 추가.
- 지도 열기에 사용한 버튼을 뗀 뒤에만 같은 버튼으로 닫기 허용.
- 기존 키보드 M·Esc와 게임패드 B의 닫기, 미발견 정보 보호 유지.
- 게임패드 조작 안내가 반영된 실제 지도 화면을 README에 갱신.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 98개 통과.
- 보기 버튼 누름·유지·해제·재누름과 기존 지도 입력 검증.
- 실제 지도 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
