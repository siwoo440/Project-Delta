# 82일차 내부 시험 준비 상태 점검

---
## 판정

현재 개발용 게임은 내부 시험 완료 조건을 충족하지 못했다. 아래 항목의 구현과 실제 사람의 플레이 검증이 남았으므로 배포 준비 완료로 판단하지 않는다.

---
## 확인된 개발용 기능

- 1~5층 이동, 슬라임·고블린 시험 조우, 일반 전투와 별도 시험 전투.
- 시험 상자·함정·이벤트 한 종류, 시험 상인, 체력·마나를 회복하는 휴식 공간.
- 시험 회차 저장·재개, 일시정지와 설정 화면, 시험 결말과 기록.
- 새 회차의 접근 가능한 1층 휴식 방 검증. 기존 저장은 기존 구조를 유지한다.

---
## 내부 시험 전 남은 작업

| 구분 | 남은 내용 |
|---|---|
| 시험 범위 | 1층 계단의 시험 종료 안내와 시험·정식 저장 분리. 현재 개발용 2~5층·마왕·파편 기록 노출 제한. |
| 시작 흐름 | 프롤로그, 이름 입력, 난이도와 시작 설정. |
| 콘텐츠 | 내부 시험 일반 이벤트 5종, 슬라임·고블린 종별 규칙과 NPC 서비스를 기획 기준으로 검증. |
| 자원·접근성 | 탐험 정력과 휴식 정력 회복, 스트리밍 대체 이미지·텍스트·음성, 입력과 화면 접근성. |
| 실기 검증 | 실제 플레이 30~60분과 저장 복구, 여러 해상도 가독성, 최소 사양 후보 PC 성능, 주요 결함 점검. |
| 기획 확인 | 내부 시험 파편 획득 규칙, 정식 몬스터 목표와 업적 합계의 문서 간 불일치. |

| 단계 | 방향 |
|---|---|
| 83일차 | 시험 범위와 저장 식별 분리, 계단 종료 흐름. |
| 84일차 | 1층 일반 이벤트와 슬라임·고블린의 시험 콘텐츠 보완. |
| 85일차 | 프롤로그·이름·난이도와 시작 설정 연결. |

| 87일차 | 사람의 실제 플레이, 다양한 해상도와 최소 사양 후보 PC 점검. |
| 88일차 | 발견된 결함과 저장 복구 문제 수정, 내부 시험 준비 상태 재판정. |

이는 남은 내부 시험 작업을 묶은 임시 순서이며 각 단계의 실제 소요와 정식 게임 완성을 보장하지 않는다. 정식 콘텐츠 확장은 내부 시험 이후 별도로 산정한다.
