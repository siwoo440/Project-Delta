# 48일차 비밀 통로 설계

층별 비밀방 수와 발견 확률은 아직 확정되지 않았다. 시험 범위에서는 일반 방에 비밀방 한 곳을 결정적으로 연결한다. 플레이어가 단서가 있는 벽을 조사하면 발견 상태가 되고, 다시 상호작용하면 통로가 열리며, 이후 출입할 수 있다. 발견 전에는 비밀방과 통로를 표시하지 않고 발견 후 미방문 방은 비활성 칸으로 표시한다. 발견과 개방은 별도 상태로 저장한다.

이전 회차의 던전 구조 변경을 피하도록 기존 저장의 생성 규칙은 유지하고 새 회차만 새로운 생성 버전을 사용한다. 새로운 저장 형식에서는 생성 버전과 비밀 상태를 검증한다. 이전 저장의 구조를 새 규칙으로 재생성하지 않는다.
