# 77일차 일반 전투 관찰

---
## 구현

- 짧은 조우 연출 후 자동 전투 진입을 유지하고 일반 전투 관찰 버튼을 활성화했다.
- Delta-old의 전투 관찰처럼 선택한 생존 상대의 현재 체력·공격·방어·속도를 표시하고 플레이어 행동을 소모한다.
- 다수 적은 직접 대상을 선택하며 대상이 없으면 행동을 소모하지 않는다.
- 항복 확인과 아이템 선택 중 관찰을 차단하고 취소하면 복구한다.
- 전투 관찰은 조우 관찰 판정과 별개로 영구 도감을 해금하지 않는다. 별도 전투 관찰의 영구 도감 연결은 후속 규칙 확인이 필요하다.

---
## 검증

- 구현 전 실제 슬라임 관찰 테스트에서 버튼 비활성화 실패 확인.
- Unity 6000.3.21f1 PlayMode 전투 회귀 9개 통과.
- 실제 슬라임 관찰 화면 캡처 테스트 1개 통과.
- 실제 고블린 두 개체의 대상 선택과 항복 확인 입력 차단 검증.
