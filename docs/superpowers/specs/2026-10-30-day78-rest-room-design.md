# 78일차 휴식 방 설계

---
## 기준과 범위

- 기획서의 휴식 방은 층당 최대 하나이며 플레이어가 선택해 사용하면 최대 체력과 마나의 30%를 한 번 회복한다.
- 탐험 회차의 정력은 미구현이므로 정력 회복은 지원하지 않으며 화면에 표시한다.
- 회복·사용 완료·탐험 기록은 하나의 회차 파일에 저장하고 실패하면 전부 기존 상태를 유지한다.
- 새 회차는 상인보다 휴식을 먼저 배치하며 두 방 모두 잠긴 말단 방을 피한다. 기존 버전의 회차는 기존 상인 배치 순서를 유지한다.
- 기존 상자·함정·조우·이벤트 방과 충돌하지 않는다. 빈 방이 없으면 기존 콘텐츠와 층 이동을 보존하고 휴식 방은 생략한다.
- 1층 시험 배치에서 접근 가능한 휴식 방을 보장하려면 선택적 콘텐츠의 생성 규칙을 별도로 보완해야 한다.
