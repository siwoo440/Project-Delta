# 44일차: 회차 저장과 이어하기

- 탐험 화면에서 K, 게임패드 오른쪽 스틱 버튼, 마우스 버튼으로 회차 저장 추가.
- 타이틀 이어하기에서 시드·현재 층·방·위치·방향·체력·인벤토리·열쇠 복원 추가.
- 현재 층의 방문·시험 문·조우 상태와 회차 탐험 기록 복원 추가.
- 관찰 기록과 별개 회차 파일의 체크섬 검사, 임시 파일 교체, 기존 파일 백업, 충돌·손상 파일 보호 추가.
- 잘못된 방·플레이어 위치는 거절하고 기존 파일 보존. 자동 백업 복구와 저장 데이터 마이그레이션은 후속 작업.
- 독립 Unity 복사본에서 EditMode 166개, PlayMode 105개 및 실제 플레이 화면 캡처 1개 통과.
