# 8일차: 전투 라운드와 행동 순서

---
## 구현 내용

- 살아 있는 전투 참가자를 속도 내림차순으로 정렬.
- 속도가 같으면 플레이어를 먼저, 적은 슬롯 순서로 배치.
- 참가자의 행동 완료 전 중복 진행과 모든 행동 전 라운드 종료 차단.
- 행동 전에 사망한 참가자를 건너뛰고 완료 후 다음 라운드 시작.
- 시험 전투 화면에 라운드와 현재 행동자를 표시하고 시험 진행 버튼 추가.
- 기준: [기존 행동 순서 규칙](https://github.com/siwoo440/Project-Delta-old-/blob/main/Assets/ProjectDelta/Scripts/Application/BattleTurnOrder.cs).

---
## 범위

화면의 참가자 속도는 실제 능력치 연결 전의 시험값이다. 공격·피해·승패·상태 이상은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 67개와 PlayMode 테스트 34개 통과.
- 키보드·게임패드의 행동 진행과 탐험 복귀 검증.
- 최신 전투 화면 캡처 테스트 1개 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
