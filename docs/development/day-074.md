# 74일차 : 내부 시험 수집 기록 화면 추가

---
## 개발 내용

- 타이틀의 내부 시험 수집 기록 화면 추가
- 실제 확인된 결말·관찰·패배 기록과 시험 진행 상태 표시 추가
- 미해금 결말 이름과 상세 조건 비공개 추가
- 관찰·패배 기록 페이지 이동과 키보드·게임패드 닫기 추가
- 독립 읽기 조회 및 손상·실행 중 파일 삭제의 확인 불가 표시 추가
- 정식 엔딩·Steam 업적과 내부 시험 기록의 구분 추가
- 최신 실제 플레이·타이틀·수집 화면 수정

---
## 시험 범위

- 공식 엔딩과 Steam 업적 해금·동기화는 구현하지 않았다.
- 시험 화면은 현재 구현된 일곱 결말과 관찰·패배 기록만 표시한다.
- 공식 업적 총수와 파편 획득 조건은 기획서 내 표가 상충하므로 확정하지 않았다.
- 앱 시작 전에 파일과 모든 복구 기록이 이미 사라진 경우에는 최초 빈 저장과 구분할 근거가 없다.

---
## 검증

- Unity 6000.3.21f1 수집 화면 PlayMode 7개 통과
- 기존 관찰 도감 화면 회귀 PlayMode 3개 통과
- 실제 결말 플레이·타이틀·수집 화면 캡처 테스트 각각 1개 통과
