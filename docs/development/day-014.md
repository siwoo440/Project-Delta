# 14일차: 잠긴 문 강제 개방

---
## 구현 내용

- 기획서의 공격력 기반 일반 이벤트 판정과 1~20 주사위 두 개, 동점 성공 규칙 추가.
- 잠긴 문 앞에서 F 또는 게임패드 서쪽 버튼으로 강제 개방 시도.
- 강제 개방 성공 시 양방향 잠금을 해제하고, 실패 시 재시도를 막되 열쇠 사용 허용.
- 인벤토리와 전투 등 탐험 외 화면에서는 강제 개방 입력 차단.
- 기준: 사용자가 제공한 기획서의 잠긴 문 및 일반 이벤트 판정.

---
## 범위

공격력 50, 선택 보정 0, 문 난이도 50은 현재 개발용 시험 수치다. 능력치 성장·유물의 이벤트 보정과 문별 정식 난이도는 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 95개와 PlayMode 테스트 48개 통과.
- 주사위 경계·동점·실패 후 재시도 제한·열쇠 사용과 키보드·게임패드 입력 검증.
- 실제 탐험 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
