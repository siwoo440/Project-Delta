# 72일차 : 회차 완주와 결말 기록 추가

---
## 개발 내용

- 새 회차부터 다섯 층과 마왕 전투를 거쳐 결말에 도달하는 시험 흐름 추가
- 현실 귀환·던전 잔류의 확인된 복수 결말 후보와 직접 선택 추가
- 빈손·저체력의 확인 가능한 귀환 후보 추가
- 마왕 패배·항복의 마왕의 종 결말과 원인별 영구 패배 기록 추가
- 결말 후보·선택 선행 저장과 중단 후 동일 거래 복원 추가
- 최초 결말 해금 파편의 중복 지급 방지와 영구 기록 추가
- 결말·패배 기록의 손상·삭제·잠금 시 회차 종료 차단 추가
- 전투 전환 화면이 닫힌 뒤 페이드가 실행되는 오류 수정
- 최신 실제 결말 선택 화면 수정

---
## 시험 범위

- 정력·관계·도감·전층 탐색·저주 합산 등의 미구현 조건은 판정하지 않는다.
- 난이도별 매 회차 완료 파편과 파편 소비·영구 성장 기능은 아직 구현되지 않았다.
- 마왕 별도 이벤트 전투와 전투 중 재개는 아직 구현되지 않았다.
- 모든 목표 결말과 몬스터·NPC 콘텐츠의 구현 완료를 의미하지 않는다.

---
## 검증

- Unity 6000.3.21f1 전체 EditMode 377개 통과
- 다섯 층의 실제 이동·마왕전·직접 선택·영구 기록·회차 종료 및 손상·잠금 복구 집중 PlayMode 5개 통과
- 기존 마왕전과 새 결말 복원 집중 PlayMode 3개 통과
- 실제 결말 선택 화면 캡처 PlayMode 1개 통과
- 첫 집중 실행은 Unity 복사본 정규화와 전환 화면 종료 오류를 확인해 수정했으며, 수정 후 재실행이 통과했다.
- 중간 재실행에서 결말 선택 저장 실패가 한 차례 발생했으며 정확한 원인은 확인되지 않았다. 이후 집중 테스트 재실행은 통과했다.
- 전체 PlayMode 174개 통과
