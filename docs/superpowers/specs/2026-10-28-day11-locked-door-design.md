# 11일차 잠긴 문과 열쇠 설계

---
## 목표와 규칙

- 기존 프로젝트와 같이 잠긴 문은 열쇠가 없으면 열 수 없고, 열쇠가 있으면 한 개를 소모해 연다.
- 같은 방 연결의 양방향은 하나의 잠금 상태를 공유한다. 이미 열린 문은 열쇠를 다시 소모하지 않는다.
- 기존 생성 규칙에 없는 임의의 잠금 확률은 만들지 않는다. 이번 단계에서는 필수 진행 방을 막지 않는 일반 말단 방의 연결 하나를 시험 잠긴 문으로 선택한다.
- 시험 열쇠 지급은 개발 확인용이다. 정식 열쇠 획득과 저장은 후속 작업이다.
- 도착 칸 차단 등 방 이동 실패 시 잠금과 열쇠를 원래 상태로 복구한다.
- 이전 프로젝트의 확인된 코드에 강제 개방 규칙이 없어 힘 판정은 이번 범위에서 제외한다.
- 최신 실제 플레이 화면을 화면 밖에서 캡처하고 사용자 화면을 조작하지 않는다.

---
## 기준

기존 GridPassage.TryOpenDoor와 PlayerDoorInteractionController의 열쇠 보유·소모 규칙을 참고해 새 코드로 구현한다.
