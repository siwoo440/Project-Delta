# 4일차 탐험 지도 구현 계획

---
## 구조

- Core: 방 좌표와 정의, 양방향 출구, 방문·발견 상태.
- Runtime: 동일한 방 정의의 씬 연결, 방 이동 성공 통지와 미니맵 표시.
- Editor: 기존 시험 방을 보존하며 세 번째 방과 출구 연결, 전용 Windows 빌드.
- Tests: 순수 지도 상태, 실제 방 이동과 표시, 기존 씬·이동 회귀, Windows 화면.

---
## 순서

1. 실패하는 방 구조와 방문·비밀 정보 테스트 작성 후 Core 구현과 EditMode 검증.
2. 실제 방 이동·방문 표시 테스트 작성 후 씬 데이터와 미니맵 구현 및 PlayMode 검증.
3. 씬 보존·기존 기능·Windows 실행 파일과 일반 빌드 검증.
4. 결과를 기록하고 `4일차 : 작업 내용` 형식으로 커밋과 푸시.
