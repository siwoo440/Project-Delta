# 5일차 1층 생성 구현 계획

---
## 구조

- Core: 시드 기반 방 좌표·방 종류·경로 생성과 생성 결과 검증.
- Runtime: 생성 데이터를 시험 방 인스턴스·플레이어·미니맵에 연결.
- Editor: 기존 프로젝트를 보존하며 분리된 Windows 빌드 제공.
- Tests: 다중 시드와 실제 방 이동, 미니맵 공개 범위, 대체 구조, Windows 화면 검증.
- README: 최신 실제 플레이 화면의 스크린샷과 실행 안내.

---
## 순서

1. 방 수·연결·계단 거리·결정성·재시도에 대한 실패 테스트 작성 후 생성 규칙 구현.
2. 생성된 출구와 실제 방 이동, 미니맵 표시의 실패 테스트 작성 후 Runtime 연결.
3. 기존 회귀, 다중 시드, Windows 실행 화면과 일반 빌드 검증.
4. 플레이 스크린샷과 개발 기록 갱신 후 `5일차 : 작업 내용` 형식으로 커밋과 푸시.
