# 38일차: 최근 탐험 기록

---
## 구현 내용

- 실제 방 진입과 문 상호작용 안내를 탐험 화면 오른쪽에 기록.
- 빈 안내를 제외하고 최근 네 개만 화면에 표시.
- 기존 이동과 문 판정은 유지.
- 방 전환 완료 후 최근 기록이 보이는 실제 화면을 README에 갱신.

---
## 범위

현재 기록은 던전 화면의 임시 기록이다. 회차 전체 기록과 별도 이력 화면은 아직 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 99개 통과.
- 실제 방 이동, 문 강제 개방 실패와 최근 기록 제한 추가 검증.
- 방 전환 완료 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
