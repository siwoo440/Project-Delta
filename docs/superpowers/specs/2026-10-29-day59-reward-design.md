# 59일차 시험 전투 보상 설계

---
## 지급 범위

- 일반 전투 승리에서 생존 상대가 없을 때만 보상을 확정한다.
- 1층 일반 몬스터의 기본 경험치는 개체당 60, 2층은 80이다. 상위 시험 상대는 해당 층 기준의 3배다.
- 레벨 상승, 요구 경험치, 스탯 포인트와 최대 레벨은 기획 기준으로 계산한다.
- 일반 전투 소비 아이템 드롭은 개체당 30%, 상위 개체는 70%의 시험 밸런스를 사용한다.
- 골드 획득량은 기획서에서 확정되지 않아 시험값으로 구분한다.
- 도주·항복·패배에는 보상을 지급하지 않는다.

---
## 중복 방지와 보존

- 같은 조우의 완료 상태와 보상은 현재 회차의 저장본에서 함께 기록한다.
- 보상 후보와 획득 또는 포기 상태를 저장해 재실행 시 재추첨을 방지한다.
- 수용 공간이 부족할 때 아이템을 자동 삭제하거나 기존 슬롯을 덮어쓰지 않는다.
- 저장 실패 및 이전 저장 복원 시 보상과 조우 완료 상태가 서로 다른 시점으로 갈라지지 않도록 검증한다.

---
## 검증

- 단일·다수 적 승리, 상위 개체, 도주·항복, 반복 확인과 저장 재개를 확인한다.
- 만렙과 연속 레벨 상승, 부족한 인벤토리 공간을 확인한다.
