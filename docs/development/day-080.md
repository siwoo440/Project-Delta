# 80일차 휴식 공간 이미지 적용

---
## 구현

- 이미지 생성으로 일본 애니메이션풍의 침낭·랜턴·가방을 제작하고 투명 배경의 휴식 소품으로 적용.
- 소품 이미지가 없을 때 기존 단색 표시를 사용하며 휴식 사용 후 표시 제거 유지.
- 실제 던전에서 휴식 소품이 보이는 최신 플레이 화면으로 README 이미지 갱신.

---
## 검증

- 적용 전 실제 휴식 방이 흰색 텍스처를 사용해 새 이미지 검증에 실패하는 것을 확인.
- 휴식·이벤트·새 게임과 저장 재개 관련 PlayMode 테스트 6개 통과.
- 실제 던전 휴식 소품 화면 캡처 테스트 통과.
