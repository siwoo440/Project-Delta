# 76일차 내부 시험 검증 계획

---
## 목표

현행 기획서의 내부 시험 완료 조건과 현재 실행 범위를 비교하고, 자동 테스트 및 격리된 Windows 빌드 결과를 근거로 남은 작업을 정리한다. 자동 검증만으로 실제 사람의 재미·가독성·실기 성능 또는 전체 결함 부재를 판정하지 않는다.

---
## 범위와 충돌

기획서 내부 시험은 1층과 슬라임·고블린 중심이며 2~5층·상위 개체·마왕·정식 엔딩과 영구 성장 사용을 제외한다. 현재 5층과 마왕은 별도 개발 검증용 흐름으로 보존한다. 파편 획득 허용 여부 및 공식 업적 총수는 기획서 항목 간 상충하므로 확정하지 않는다.

---
## 검증

격리 Unity 프로젝트에서 EditMode·PlayMode 전체 테스트와 Windows 빌드를 실행한다. 시험 범위의 실제 화면을 캡처하고 이전 사용자 Unity 설정과 프로젝트를 건드리지 않는다. 실패와 미검증 항목은 결과 보고서에 그대로 기록한다.
