# 2일차 격자 이동 설계

---
## 목표

던전의 임시 플레이어가 화면 기준 상하좌우로 한 칸씩 이동하고, 벽과 장애물에서 멈추며 현재 방향을 표시한다. 논리 좌표는 2D X·Y를 사용한다. 한 번의 입력은 한 칸, 이동 중 대기 입력은 최대 한 개다.

---
## 규칙과 구조

- Core는 칸 좌표, 네 방향, 이동 확정, 이동 중 단일 입력 대기를 관리한다.
- Runtime은 Input System의 실제 이동 입력, Tilemap의 유효 칸·장애물, 위치 보간, 방향 화살표를 연결한다.
- 대각 입력은 축의 크기가 큰 방향 하나로 정하고 크기가 같으면 가로 방향을 사용한다.
- 이동 불가 시 논리 위치와 표시 위치를 유지한다. 입력이 잠기면 대기 중인 입력을 버린다.
- 이동 중 입력 맵이 비활성화되면 이동 표시를 일시 정지하고 기존 대기 입력을 제거한다.
- 현재 방의 격자 좌표와 이후 층 지도에서 사용하는 방 좌표는 별개다.
- 현재 DungeonScene의 Floor 타일맵이 비어 있으므로 기존 13×9 바닥을 실제 타일로 구성하고 장애물 칸을 추가한다.
- 씬 초기화 코드는 기존 DungeonScene에 필요한 요소만 추가하고 저장 후 다시 열어 검증한다. 1일차 씬 재생성 도구도 2일차 구성을 포함한다.

---
## 완료 기준

키보드·게임패드 방향 입력, 장애물·경계 차단, 네 방향 표시, 한 칸 입력 대기, 입력 잠금, 기존 타이틀 복귀를 EditMode와 실제 씬의 PlayMode에서 검증한다. Windows 빌드와 실행 파일 테스트를 확인하고 2일차 커밋을 지정 저장소에 푸시한다.
