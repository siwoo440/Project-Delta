# 46일차: 던전 구조 재개 검증

- 현재 층의 방·문 구조를 순서와 무관한 지문으로 저장하고 재개 시 재생성 결과와 비교.
- 새 회차 저장 형식을 버전 2로 확장하고 기존 버전 1을 현재 생성 규칙 기준으로 계속 읽기.
- 버전 1 저장에는 과거 구조 지문이 없어 당시 구조와의 완전 일치 여부를 확인할 수 없음.
- 방과 문 목록 순서, 방 역할 변화, 구조 지문 누락과 불일치, 새 실행의 저장 재개 검증 추가.
- 독립 Unity 복사본에서 EditMode 174개, PlayMode 106개, 실제 플레이 화면 캡처 1개 통과.
