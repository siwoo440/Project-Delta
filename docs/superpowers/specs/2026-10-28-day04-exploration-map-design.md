# 4일차 방 정보와 미니맵 설계

---
## 목표

서로 연결된 고정 시험 방 세 개를 데이터로 정의하고 실제 방 이동과 미니맵이 같은 정보를 사용한다. 시작 방과 이동에 성공한 방만 방문으로 기록하고, 방문 방과 연결된 일반 미방문 방은 어두운 윤곽으로 표시한다.

---
## 기준

- 방 정의·문 연결·방문 기록은 Unity에 의존하지 않는 Core에 둔다.
- Runtime은 동일한 방 정의를 실제 씬 객체에 연결하고, 성공한 이동 뒤에만 방문 상태를 갱신한다.
- 새 게임은 시작 방만 방문 처리하며 비밀 방은 직접 방문하기 전 지도에 표시하지 않는다.
- 발견되지 않은 방과 비밀 통로는 화면 객체와 지도 연결선으로 노출하지 않는다.
- 기존 방 이동, 장애물, 도착 실패 복구와 사용자 씬 보존 규칙을 유지한다.
- 무작위 생성, 비밀벽 발견, 지도 구입, 저장·복원은 후속 작업이다.

---
## 검증

좌표 중복과 연결 일관성, 시작·방문·연결 발견·비밀 정보 가림, 실패한 이동과 새 게임 초기화, 실제 키보드 이동 및 미니맵 화면 표시, 기존 회귀와 Windows 실행 파일을 검증한다.
