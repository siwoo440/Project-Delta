# 83일차 UI 이미지 적용

- 탐험과 미니맵, 기록·설정·인벤토리·지도·타이틀에는 청록색 던전 패널 적용.
- 전투·조우·보상·보스 화면에는 붉은 금속 패널 적용.
- 상점·상자·휴식·이벤트·결말 화면에는 금색 대화 패널 적용.
- 공통 버튼에 녹색 이미지 적용 및 버튼 상태 색상 연결.
- 장식 이미지의 입력 차단 방지와 크기별 테두리 유지.
- 지도 방과 연결선, 조우 전환 효과는 기존 동작 유지.
- 이미지 생성: 내장 imagegen, 일본 애니메이션풍 판타지 RPG 패널과 버튼, 글자 없는 어두운 중심 및 투명 외곽.
