# 39일차: 회복약 사용 기록

---
## 구현 내용

- 실제 소비와 체력 회복이 성공한 회복약 사용을 최근 탐험 기록에 추가.
- 탐험 화면에서 잘못 사용하거나 회복이 불가능한 경우 성공 기록을 남기지 않음.
- 기존 회복 수치와 아이템 소비 판정 유지.
- 회복약 사용 후 실제 탐험 화면을 README에 갱신.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 99개 통과.
- 잘못된 상태의 사용 실패와 게임패드 회복 성공 기록 검증.
- 실제 회복 후 탐험 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
