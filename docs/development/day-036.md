# 36일차: 마우스 지도 버튼

---
## 구현 내용

- 탐험 화면에 마우스용 전체 지도 열기 버튼 추가.
- 전체 지도 화면에 마우스용 닫기 버튼 추가.
- 마우스 입력 이벤트를 사용해 클릭을 놓치지 않도록 처리.
- 기존 키보드·게임패드 지도 입력과 탐험 상태 복구 유지.
- 실제 지도 버튼 화면을 README에 갱신.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 99개 통과.
- 실제 마우스 클릭의 지도 열기·닫기와 기존 입력 검증.
- 실제 지도 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
