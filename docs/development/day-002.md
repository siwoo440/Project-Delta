# 2일차: 2D 격자 이동 및 충돌 구현

---
## 구현 내용

- 논리 좌표 X·Y와 화면 위치를 분리하고 상하좌우 한 칸 이동 추가.
- WASD·방향키·게임패드 방향 버튼과 스틱 입력 연결.
- 바닥이 없는 칸과 장애물 칸의 이동 차단.
- 이동 중 입력 한 개만 대기하고 입력 잠금 시 대기 입력 제거.
- 방향 화살표와 한 칸 이동 보간 추가.
- 화면 전환 전 누른 방향과 전환 직후 새로 누른 방향 구분.
- 실제 13×9 바닥과 시험 장애물 세 칸을 던전 씬에 저장.
- 장애물 전용 이미지와 타일을 추가하고 기존 시험 장애물의 화면 표시 수정.
- 기존 바닥 구멍·장애물과 미저장 씬 변경 보호.
- 사용 중인 1일차 실행 파일과 분리된 `Builds/Day02` 빌드 경로 추가.

---
## 개발 중 확인한 내용

1일차 안내와 달리 기존에 저장된 Floor 타일맵이 비어 있었다. 2일차 씬 구성에서 바닥을 채우고 저장한 씬을 다시 열어 타일이 유지되는지 확인했다.

자동 실행에서는 미저장 씬이 열려 있으면 던전 구성 작업을 중단한다. 대화형 편집기에서는 Unity의 씬 저장·취소 확인을 사용한다. 이미 타일이 있는 바닥은 빈 칸을 임의로 채우지 않는다.

기존 시험 장애물은 어두운 바닥 이미지를 사용해 화면에서 구분하기 어려웠다. 정확히 일치하는 시험 배치만 밝은 전용 타일로 교체하며, 그 외 기존 장애물과 색상은 유지한다.
