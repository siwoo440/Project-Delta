# 6일차 계단과 층 이동 구현 계획

**목표:** 계단 방에서 다음 층으로 이동하고 새 층의 방문 정보와 위치를 표시한다.

**구조:** 순수 층 상태와 실제 Unity 방 교체를 분리한다. 원본 방 템플릿을 실행 중 보관해 새 층을 준비하고 검증 후 교체한다.

**환경:** Unity 6000.3.21f1, URP 2D, C#.

---
## 구현 및 검증 순서

1. 층 전환 상태와 중복 요청의 실패 테스트 작성 및 순수 상태 구현.
2. 기존 방 원형을 보관하고 계단 표시와 격자 상호작용, 실패 시 이전 방 보존 구현.
3. 층 번호와 독립된 방문 기록을 화면에 연결하고 실제 입력 통합 테스트 작성.
4. EditMode·PlayMode와 Windows 빌드를 별도 프로젝트에서 검증.
5. 실제 게임 화면을 화면 밖에서 캡처해 README에 반영하고 검증 기록과 함께 커밋.

---
## 주의 조건

- 2층에만 1층 생성 규칙 임시 적용, 이전 층 복귀와 3층 이동 불가.
- 이동 중이나 계단 이외의 위치에서 상호작용 시 층 변화 없음.
- 중복 입력, 생성 실패, 도착 칸 차단 시 기존 층과 위치 보존.
- 사용자 편집기, 사용자 설정과 입력 장치를 건드리지 않음.
