# 24일차: 시험 소형 회복약 사용

---
## 구현 내용

- 현재 기획서의 소형 회복약 기준을 시험 데이터로 적용: 체력 25 회복, 최대 5개 중첩.
- 탐험 인벤토리에서 회복약 지급과 사용, 현재 체력 및 사용 결과 표시.
- 체력이 최대이거나 사용 조건을 만족하지 않으면 아이템과 체력을 보존.
- 가방이 가득 차면 회복약에도 기존 획득 선택과 교체 확인을 적용.

---
## 범위

시험 지급은 개발 확인용이며 수치도 실제 플레이 검증 전의 기획 기준이다. 전투 중 아이템 사용, 정식 아이템 데이터와 회차 저장은 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 141개와 PlayMode 테스트 82개 통과.
- 회복량·최대 체력·잘못된 사용과 중첩·조건부 소비 검증.
- 가득 참 교체, 게임패드 사용과 인벤토리 외 직접 사용 차단 검증.
- 실제 회복약 사용 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
