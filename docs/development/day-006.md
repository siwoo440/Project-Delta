# 6일차: 계단과 층 이동

---
## 구현 내용

- 계단 방 중앙에서 상호작용해 새 층으로 이동.
- 현재 층과 방을 화면에 표시하고 새 층의 방문 기록을 독립적으로 생성.
- 새 층 준비 실패, 계단 칸 충돌과 같은 프레임 중복 입력 처리.
- 방 원형을 미리 검증하고 준비 중 방 객체의 조기 활성화 방지.
- 2층은 1층 생성 규칙을 임시 적용하며 이전 층 복귀와 3층 이동 차단.
- 실제 2층 게임 카메라와 UI를 화면 밖에서 렌더링해 README 갱신.

---
## 범위

2층 생성 조건은 사용자가 정한 임시 규칙이다. 원래 기획의 추가 층 규칙은 확인이 필요하다. 전투와 상위 개체 조우는 후속 작업이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 56개 통과.
- PlayMode 테스트 32개와 실제 2층 화면 캡처 테스트 1개 통과.
- Unity 6000.3.21f1 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
