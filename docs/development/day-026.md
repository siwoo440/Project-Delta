# 26일차: 일반 전투 후퇴 규칙

---
## 구현 내용

- 현재 기획서의 일반 전투 후퇴 판정에 따라 가장 빠른 생존 적과 속도·주사위를 비교하고 동점은 실패.
- 후퇴 실패 시 플레이어 행동을 소모하고 적의 행동을 진행.
- 성공 시 같은 층의 직전 방으로 이동하고 보상과 조우 완료 처리를 하지 않음.
- 시험 상위 개체의 남은 체력을 해당 층·방에 보관해 재진입 전투에서 복원.
- 직전 방 부재와 도착 실패를 안전하게 처리하며 성공 판정의 재시도에서 주사위 재사용.

---
## 범위

현재 적 체력 보관은 회차 중 시험 상위 개체 한 명을 대상으로 한다. 다수 적의 개별 상태, 마왕전과 정식 후퇴 보정은 후속 작업이다. 같은 층의 직전 방 이동이며 이전 층으로의 복귀는 지원하지 않는다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 147개와 PlayMode 테스트 89개 통과.
- 동점 실패·양쪽 보정·가장 빠른 적과 주사위 범위 검증.
- 후퇴 실패의 행동 소모, 성공 후 직전 방 이동과 재진입 적 체력 복원 검증.
- 이전 방 부재와 도착 실패 후 주사위 재사용 없는 게임패드 재시도 검증.
- 실제 후퇴 후 탐험 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
