# 75일차 : 설정 화면과 조우 섬광 조절 추가

---
## 개발 내용

- 타이틀과 일시정지의 독립 설정 화면 추가
- 전체 음량의 저장·실제 적용 및 재시작 복원 추가
- 조우 섬광 기본·감소·끔 설정과 실제 전환 적용 추가
- 설정 저장 잠금·손상 시 기존 적용값과 원본 보호 추가
- 손상된 설정의 기본 또는 복구값 안내 추가
- 설정 중 뒤쪽 메뉴 입력 잠금 및 ESC·게임패드 취소 복원 추가
- 최신 실제 플레이·타이틀·수집·설정 화면 수정

---
## 시험 범위

- 현재 별도 오디오 자산이 없어 BGM·효과음 개별 음량은 지원하지 않는다.
- 키 재설정, 화면 해상도·창모드, 텍스트 및 나머지 접근성 설정은 아직 구현되지 않았다.
- 기획서의 기본 상호작용 F는 현재 문 강제 개방과 충돌하므로 기존 E 상호작용을 유지한다.
- 설정 화면은 현재 타이틀과 일시정지의 모달로 구성되며 별도 설정 씬은 아직 없다.

---
## 검증

- Unity 6000.3.21f1 전체 EditMode 415개 통과
- 실제 음량·섬광 및 설정 저장·손상·입력 PlayMode 6개 통과
- 시험 수집 화면과 상호 입력 잠금 회귀 PlayMode 7개 통과
- 실제 플레이·타이틀·수집·설정 화면 캡처 테스트 각각 1개 통과
- 기존 일시정지·저장·불러오기 회귀 PlayMode 4개 통과
