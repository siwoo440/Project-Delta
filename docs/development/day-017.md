# 17일차: 조우 단계 도망

---
## 구현 내용

- 플레이어 속도와 1~20 주사위가 가장 빠른 생존 상대의 속도와 별도 주사위보다 클 때만 도망 성공.
- 동점 또는 실패 시 일반 전투로 전환하고, 성공 시 이전 방으로 돌아가며 대상은 보존.
- 이전 방이나 안전한 도착 칸이 없을 때 도망을 차단하고 이유 표시.
- 방 활성화 중 도착 칸이 막히면 성공 판정을 보존하고 이동만 재시도.
- 도망 실패 후 전투 화면이 생성되지 않으면 도망 재판정을 막고 전투 선택 복구.
- 기준: 사용자가 제공한 기획서의 조우 단계 도망 규칙.

---
## 범위

플레이어 속도 10, 시험 상대 속도 5와 보정 0을 사용한다. 상태·아이템 보정과 여러 상대의 실제 데이터, 실패 시 기습은 후속 작업이다. 전투 중 도주는 별도의 기존 임시 확률을 사용한다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 110개와 PlayMode 테스트 56개 통과.
- 주사위 경계·동점 실패·이전 방 복귀·재조우와 이동 및 전투 화면 오류 복구 검증.
- 실제 조우 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
