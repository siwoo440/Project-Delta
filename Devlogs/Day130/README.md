# 130일차 : 상점 UI·시스템 전체 개편 및 NPC 상호작용 화면 통일

## 목표
- 기획서(구글독스) 6.5·6.6절을 확인해, 테스트 값으로만 채워져 있던 상점 가격·강화 체계를
  실제 기획 수치로 교체
- NPC 상호작용 UI를 화면 하단 고정 배치에서 벗어나 참고 이미지 구조로 재구성
- 상인 화면에서 완성한 스타일을 나머지 3명(치료사·지도사·보물사냥꾼)에게도 통일

## 구현 내용

### 1. 상점 가격 범위 규칙 (기획서 6.5절)
- `ItemPriceRangeRules`(Domain) 신설 - 카테고리별 가격 범위를 기획서 수치 그대로 반영
  (소비 20~60 / 탐험도구 30~150 / 장비 80~160 / 유물 250~600 / 저주유물 300~700 / 가방 120~700)
- `ItemDefinition`에 장비 세부 등급(고급/희귀/전설) 필드가 없어 세부 등급 구간은
  대표값으로 단순화 - 추후 등급 필드가 생기면 확장할 자리로 남김

### 2. 상점 강화 4종 (기획서 6.6절)
- `ShopUpgradeRule`(Domain) 신설 - 구매 할인(5단계, -2%~-10%), 재고 증가(3단계, +1~+3),
  희귀 상품 확률(5단계, +2%~+10%), 판매가 증가(4단계, 50%→55~70%) - 비용까지 기획서 수치 그대로
- `ProfileData`에 4개 레벨 필드, `ApplicationFlow`에 구매 메서드 4개 + 조회용
  `GetShopUpgradeSnapshot()`/`GetShopSellPriceRatio()` 추가
- 로비 강화 패널에 4종 행 추가, 반복되던 행 그리기 코드를 공용 `DrawSimpleUpgradeRow`로 정리

### 3. 실제 재고/가격 로직 교체
- `NpcShopStockBuilder`: 로드된 아이템 전부를 무제한 진열하던 방식을 버리고, 기본 6개
  (+재고 강화분) 슬롯만 층 시드 기반으로 결정론적으로 채움 - 가격은 카테고리 범위 안에서
  굴리고 할인 반영, 희귀 확률만큼 유물/저주유물 풀에서 우선 선택
- `NpcRuntimeBootstrapController`에서 층 시드+NPC ID로 호출하도록 연결해 "같은 층에서는
  유지, 층 이동 시 새로 결정"(기획서 5.3) 재현
- `ShopService`의 하드코딩된 판매가 50% 상수를 매개변수화하고 상점 강화 레벨 기반 동적
  값으로 교체

### 4. NPC 상호작용 UI 재구성
- 화면 하단에 붙어있던 대화 UI를 화면 정중앙으로 재배치
- 대화 중 뒤에 비치던 NPC 3D 모델은 화면을 덮는 대신 해당 NPC의 `Renderer`만 꺼서 숨김
  (패널 닫으면 자동 복원)
- 왼쪽 열(초상화+호감도/상태+"○○ 서비스" 라벨+대화·서비스·선물·공격 버튼)과 오른쪽 열
  (서비스 내용) 2단 구성으로 개편 - 이제 상점이 열려도 왼쪽 버튼들이 계속 보임
- 상점 화면: 골드 표시, 구매/판매 실제 탭 버튼, 카테고리 필터(전체/소비/탐험도구/장비/유물) 추가
- 회복·정보·유물 정리 화면에도 같은 골드 머리글을 적용하고, 유물 정리 목록은 상점처럼
  전용 스크롤뷰로 감싸 4개 NPC 화면 전체가 같은 골격을 공유하도록 통일

## 참고 - 이번에 반영하지 않은 부분
- 재구매(buyback) 탭, 소지품 그리드, 거래 정보 패널, 무게 바, 아이템 아이콘, 감정/수리
  서비스는 아이콘 자산이 없거나 새 시스템이 필요해 범위 밖으로 남김
- "구조" 버튼을 상인 등 공통 버튼 목록에서 뺐음 - 백엔드 로직(`ResolveRescue`)은 남겨뒀지만
  현재 UI에서는 노출되지 않음
