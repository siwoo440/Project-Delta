# 3일차 방 이동 구현 계획

---
## 구조

- Core: 방 좌표, 문 접근 조건과 도착 위치 판정.
- Runtime: 탐험 상호작용 입력, 방 전환과 플레이어 재배치.
- Editor: 기존 씬 보존, 두 번째 시험 방과 문 표시 연결, 별도 Windows 빌드.
- Tests: 방 연결 단위 검증, 실제 씬의 키보드·게임패드 왕복과 차단 검증.

---
## 순서

1. 실패하는 방 연결 테스트를 작성한 뒤 최소 규칙을 구현하고 EditMode를 검증한다.
2. 실제 씬의 문 상호작용 테스트를 작성한 뒤 입력·전환·시험 씬을 연결하고 PlayMode를 검증한다.
3. 기존 테스트와 Windows 실행 파일 테스트 및 일반 빌드를 검증한다.
4. 문서와 변경 내역을 검토하고 `3일차 : 작업 내용` 형식으로 커밋 후 원격에 반영한다.
