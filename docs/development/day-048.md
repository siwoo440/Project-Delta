# 48일차: 시험 비밀 통로

- 새 회차의 각 층에 시험 비밀방 한 곳을 생성하고, 미발견 비밀벽과 방을 숨김.
- 벽 앞 단서 조사, 발견, 개방과 출입을 별도 단계로 처리.
- 발견한 미방문 비밀방만 지도에 표시하고 방문·개방 상태를 저장.
- 회차 저장 형식 버전 3과 생성 규칙 버전을 추가하여 이전 저장의 던전 구조 보존.
- 비밀방 개수와 발견 방법은 시험값이며 기획의 정식 확률과 수량은 미확정.
- 독립 Unity 복사본에서 EditMode 179개, PlayMode 108개, 실제 비밀벽 발견 화면 캡처 1개 통과.
