# 79일차 첫 층 휴식 공간 보장

---
## 구현

- 새 회차의 씨드를 확정하기 전에 첫 층의 기존 조우·상자·함정·이벤트를 재현하고 잠긴 말단 밖의 휴식 공간을 확인한다.
- 휴식 공간이 없는 씨드는 다른 씨드로 교체하며, 저장된 회차와 자동 검증용 고정 씨드는 변경하지 않는다.
- 실제 새 게임의 저장 후 재개와 이전 버전 회차의 상인 배치 순서를 검증한다.

---
## 검증

- Unity 6000.3.21f1 EditMode 420개 통과.
- 휴식 없는 씨드 55의 결정적 교체와 선택 결과의 접근 가능 조건 검증.
- 실제 새 게임의 휴식 공간·동일 씨드 재개, 이전 버전 재개, 고정 시험 씨드 보존 검사 각각 통과.
- 실제 휴식 화면 캡처 테스트 통과. 캡처 이미지는 이전 화면과 동일.

---
## 남은 범위

- 기존 저장과 자동 검증용 고정 씨드는 구조 보존을 우선하므로 휴식 공간이 없을 수 있다.
- 탐험 정력과 휴식 정력 회복은 미구현이다. 정식 콘텐츠 수량과 내부 시험의 세부 범위 재확인, 나머지 몬스터·이벤트·서비스와 실제 기기 검증이 남았다.
