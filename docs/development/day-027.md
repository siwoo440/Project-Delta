# 27일차: 던전 시각 개선과 방 전환

---
## 구현 내용

- 바닥 타일과 플레이어의 가로·세로 크기를 두 배로 확대.
- 각 바닥 칸에 이동 판정에 영향을 주지 않는 검은 테두리 추가.
- 일본 애니메이션풍으로 생성한 바닥, 돌무더기, 문 이미지 적용.
- 문 이동과 이전 방 복귀에 부드러운 카메라 전환 및 전환 중 이동 입력 잠금 추가.
- 카메라를 현재 방의 범위에 맞춰 빈 화면을 줄이고 플레이어 추적.
- 2층에도 동일한 타일과 이미지 표시 적용.

---
## 범위

게임 규칙과 격자 좌표는 유지한다. 플레이어는 기존 시험용 표시를 확대한 상태이며 정식 캐릭터 그림은 아직 적용하지 않았다. 화면 전환은 도착 방을 슬라이드하는 방식이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 147개와 PlayMode 테스트 91개 통과.
- 타일 간격, 캐릭터 크기, 테두리, 생성 이미지, 카메라 이동과 입력 잠금 검증.
- 실제 방 이동 후 플레이 화면 캡처 테스트 통과 및 Windows 빌드 성공.
- 사용자 화면 보호를 위해 Windows 실행 파일 테스트는 실행하지 않음.
