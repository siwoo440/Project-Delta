# 29일차: 던전 안내 가독성 개선

---
## 구현 내용

- 던전 제목과 현재 위치 뒤에 어두운 안내 배경 추가.
- 조작, 방 표시와 문 상호작용 안내 뒤에 어두운 배경 추가.
- 안내 글자의 밝기를 높여 던전 바닥과 구분.
- 배경의 마우스 입력 차단을 해제해 기존 조작 유지.
- 최신 실제 플레이 화면을 README에 반영.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 147개와 PlayMode 테스트 94개 통과.
- 안내 배경의 입력 통과, 기존 게임 흐름과 실제 화면 캡처 검증.
- Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
