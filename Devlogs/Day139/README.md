# 139일차 : 메인 메뉴권 화면 정식 UI 전환 (타이틀·로비·설정)

## 목표
- 기획서 8.2절 "화면별 정식 UI" 전환의 첫 단계 - 가장 자주 보이는 진입점인 타이틀·로비·설정
  3개 화면을 `OnGUI` 임시 UI에서 런타임 Canvas UI로 전환

## 구현 내용

### 1. 공용 Canvas UI 유틸리티
- `RuntimeUiFactory`(Presentation) - CG·도전과제 갤러리(133~134일차)에서 반복되던
  런타임 Canvas 생성 보일러플레이트(EventSystem 준비, Canvas+CanvasScaler+배경+제목,
  중앙 정렬 버튼)를 공용으로 뺐다. 기존 갤러리 두 화면은 이미 검증된 상태라 건드리지 않고,
  이번에 새로 옮기는 화면 3개부터 이걸 사용

### 2. 타이틀 화면
- 이어하기(저장된 런 있을 때만)/새 게임/설정/CG 목록/도전과제/종료 버튼 구성은 그대로,
  그리는 방식만 Canvas로 전환

### 3. 설정 화면
- UI 배율 소/보통/대 3버튼(현재 선택 배경색으로 강조), 자막 표시 토글, 키 설정 패널
  (5개 액션 재설정 - 누르면 "입력 대기 중..."으로 바뀌고 다음 입력을 그대로 저장),
  뒤로가기
- OnGUI는 매 프레임 다시 그렸지만 Canvas는 값이 바뀔 때만 텍스트/버튼 색을 갱신하는
  방식으로 바꿨다(각 상태마다 Refresh 메서드 분리)

### 4. 로비 화면
- 기억의 조각/도전과제 진행도/자유 탐험 해금 상태 표시, 던전 입장/강화/타이틀로 버튼,
  강화 상점 패널(영구 스탯 3종 + 인벤토리·유물·상점 강화 4종 = 총 9개 항목)
- 구매 로직·비용 조회 로직(`PermanentStatUpgradeRule` 등)은 전혀 건드리지 않고 화면만 교체

## 버그 수정 (작업 중 자체 발견)
- 로비 강화 상점 행을 만들 때 현재 레벨을 정적 `int` 값으로 한 번만 캡처해서, 구매해도
  화면에 표시되는 레벨/비용이 갱신되지 않는 문제가 있었다 - `Func<int> getLevel` 델리게이트로
  바꿔 매번 프로필에서 다시 읽도록 수정

## 남은 사항
- NPC 상호작용/상점, 이벤트 전투 화면은 140일차에서 전환 예정
- 던전 탐험 오버레이(미니맵·문/계단 프롬프트·복귀 HUD·로딩)는 141일차 예정
