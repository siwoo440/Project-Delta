# 40일차: 회복약 획득 기록

---
## 구현 내용

- 시험 소형 회복약을 빈 공간에 획득하면 최근 탐험 기록에 표시.
- 가득 찬 가방에서 교체를 확정해 획득한 회복약도 기록.
- 아이템을 두고 가거나 교체를 확정하기 전에는 획득 기록 제외.
- 실제 회복약 획득 기록이 보이는 탐험 화면을 README에 갱신.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 99개 통과.
- 실제 획득, 공간 부족 후 포기와 확정 교체의 기록 검증.
- 실제 회복약 획득 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
