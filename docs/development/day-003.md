# 3일차: 시험 방 연결과 문 상호작용

---
## 구현 내용

- 층 지도의 방 좌표와 방 내부 이동 칸 좌표 분리.
- 서로 연결된 두 시험 방과 양방향 문 표시 추가.
- 문 앞에서 마지막으로 이동한 방향에 따라 E 또는 게임패드 남쪽 버튼으로 방 이동.
- 도착 칸의 바닥과 장애물 검사 및 막힌 도착 칸의 전환 차단.
- 이동 중 상호작용과 같은 프레임의 중복 전환·이동 차단.
- 방 활성화 중 도착 칸이 막힐 경우 이전 방과 위치 복구.
- 미저장 씬, 기존 방 객체와 기존 문 위치 타일 보존.
- 기존 실행 파일과 분리된 `Builds/Day03` Windows 빌드 경로 추가.

---
## 사용 방법

흰 화살표는 마지막 이동 방향, 노란 화살표는 연결 문을 표시한다. 문 앞에서 문 방향으로 이동한 뒤 E 또는 게임패드 남쪽 버튼을 누른다. 도착 직후 돌아가려면 방 안쪽으로 한 칸 이동한 다음 문 쪽으로 돌아와 상호작용한다.

---
## 검증 대상

방 연결 방향과 위치, 양방향 이동, 키보드·게임패드 입력, 잘못된 접근, 도착 장애물, 도착 방 활성화 중 변경, 전환 프레임의 입력, 기존 씬 보존과 기존 이동 회귀를 확인한다.

- Unity EditMode 테스트 32개 통과.
- Unity PlayMode 테스트 21개 통과.
- Windows 테스트 실행 파일에서 테스트 23개 통과. 실제 화면의 문 표시 확인 포함.
- Windows 일반 실행 파일 빌드 완료: `Builds/Day03/ProjectDelta.exe`.
