# 32일차: 낮은 체력 경고 개선

---
## 구현 내용

- 체력이 25 이하일 때 경고색에 더해 느낌표와 위험 문구 표시.
- 체력이 회복되면 경고 문구를 제거하고 기본 색상 복구.
- 기존 체력과 아이템 판정 및 입력 유지.
- 낮은 체력 상태의 실제 플레이 화면을 README에 반영.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 148개와 PlayMode 테스트 95개 통과.
- 낮은 체력 문구, 회복 후 경고 해제와 실제 화면 캡처 검증.
- Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
