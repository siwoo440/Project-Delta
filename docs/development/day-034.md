# 34일차: 발견한 전체 지도

---
## 구현 내용

- 탐험 중 M 키로 현재 층의 발견한 전체 지도 열기 추가.
- 지도 화면에서 탐험 입력을 잠그고 M, Esc 또는 게임패드 B로 닫을 때 복구.
- 방문한 방과 연결만 확인한 방을 구분하고 미발견 방과 비밀 연결을 숨김.
- 방문한 계단 방과 현재 방을 표시.
- 실제 전체 지도 화면을 README에 반영.

---
## 범위

NPC·보물 등의 아이콘 필터와 마우스로 지도 열기는 아직 구현하지 않았다. 게임패드에서는 열린 지도를 B 버튼으로 닫을 수 있다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 149개와 PlayMode 테스트 96개 통과.
- M·Esc와 게임패드 B의 지도 닫기, 탐험 입력 복구와 미발견 방 보호 추가 검증.
- 실제 전체 지도 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
