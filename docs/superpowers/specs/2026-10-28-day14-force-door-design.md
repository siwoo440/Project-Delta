# 14일차 잠긴 문 강제 개방 설계

---
## 목표와 기준

- 사용자가 제공한 기획서의 잠긴 문과 일반 이벤트 규칙을 적용한다.
- 공격력과 선택지 보정, 1~20 주사위를 더한 값이 난이도와 별도 1~20 주사위를 더한 값 이상이면 성공한다.
- 현재 성장과 이벤트 데이터가 없어 시험 공격력 50, 보정 0, 난이도 50을 사용하고 화면에 시험값을 명시한다.
- 문마다 강제 개방은 한 번만 시도하며 실패해도 열쇠를 사용할 수 있다. 성공하면 같은 연결의 양방향 잠금을 열고 이동은 별도로 처리한다.
- F 또는 게임패드 서쪽 버튼으로 정면 잠긴 문을 강제 개방하고, E 또는 남쪽 버튼으로 열쇠 사용과 문 이동을 유지한다.
- 층별 잠금과 별도 게임 상태를 보존하며 사용자 화면을 조작하지 않는다.

---
## 후속 범위

공격력 성장·유물 이벤트 보정과 정식 문별 난이도 데이터는 아직 없으므로 시험값을 사용한다.
