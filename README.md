# 프로젝트 델타

2D 탑뷰 격자 탐험과 별도 턴제 전투, 선택·관계 중심 로그라이트 프로젝트.

기존 기획의 기능과 규칙을 기준으로 코드를 새로 작성한다. 현재는 기본 실행 흐름, 2D 격자 이동, 무작위 던전, 2층 이동, 미니맵, 조우 선택·회유, 기본 공격·방어·도주 전투, 10칸 인벤토리와 시험용 잠긴 문을 제공한다. 전투 화면에는 일본 애니메이션풍 임시 초상화를 표시한다.

## 실행

Unity Hub에서 저장소 폴더를 프로젝트로 추가하고 `Assets/ProjectDelta/Scenes/BootstrapScene.unity`를 열어 Play를 실행한다.

타이틀에서 새 게임을 선택하면 던전에 진입하고, 관찰 기록을 선택하면 저장된 시험 대상의 정보를 확인할 수 있다. 던전에서 WASD·방향키·게임패드 방향 입력으로 한 칸씩 이동하고, Esc 또는 게임패드의 취소 버튼으로 타이틀에 복귀한다. SD 주인공은 이동 방향에 따라 네 방향 이미지로 바뀌고 아래의 흰 화살표는 바라보는 방향, 돌무더기는 장애물, 갈색 문은 출구다. 타일과 플레이어는 기존보다 가로·세로 두 배 크기이며, 검은 테두리로 각 칸을 구분한다. 카메라는 방의 범위를 고려해 플레이어를 따라간다. 방을 이동할 때 화면이 부드럽게 전환된다. 오른쪽 최근 기록에는 방 진입, 문 상호작용과 성공한 회복약 획득·사용이 최대 네 개까지 표시된다. 전체 탐험 기록은 현재 회차 동안 보관되며 새 게임에서 초기화된다. H 키, 게임패드 왼쪽 스틱 버튼 또는 회차 기록 버튼으로 전체 기록을 열고 페이지를 이동할 수 있다. 미니맵은 현재 방을 중심으로 주변 5×5 범위의 발견한 방과 연결을 표시한다. 직접 방문한 계단 방에는 파란 표시가 나타난다. M 키 또는 게임패드 보기 버튼으로 발견한 방의 전체 지도를 열고 같은 버튼, Esc 또는 패드 B로 닫을 수 있다. 탐험 화면과 지도 화면의 버튼을 마우스로 눌러 열고 닫을 수도 있다. 문 앞에서 문 방향으로 마지막 이동을 마친 뒤 E 또는 게임패드의 남쪽 버튼을 누르면 다른 방으로 이동한다. 도착 직후 돌아가려면 방 안쪽으로 한 칸 이동한 뒤 문 쪽으로 돌아와 상호작용한다. 계단 방 중앙의 파란 화살표에 서서 E 또는 게임패드 남쪽 버튼을 누르면 다음 층으로 이동한다. 상위 개체 방에서 분홍 대상 주변 한 칸에 이동을 마치면 조우 화면이 열리고, 전투를 선택하면 시험 전투가 시작된다. 조우 화면에서 도망에 성공하면 이전 방으로 돌아가며 대상은 남는다. 조우 도망 실패나 동점은 전투로 이어진다. 회유에 성공하면 시험 조우를 보상 없이 평화적으로 끝내며 실패하면 전투로 이어진다. 매력과 저항은 시험 수치다. 관찰에 성공하면 시험 상대의 체력과 공격 성향을 확인할 수 있다. 관찰 기록은 2D 전용 저장 파일에 보관되어 새 게임과 재시작 이후에도 유지된다. 정식 도감 목록과 대상별 회유 결과·유혹·아이템 선택은 후속 작업이다. 전투에서 기본 공격·방어·회복약을 사용하면 적도 기본 공격으로 대응한다. 시험 회복약은 실제 회복에 성공할 때 한 개와 행동을 소비한다. 방어는 행동을 소모해 다음 자신의 차례까지 직접 피해를 줄인다. 일반 전투 후퇴는 플레이어와 가장 빠른 생존 적의 속도에 각각 1~20 주사위를 더해 비교하며 동점은 실패한다. 성공하면 보상 없이 같은 층의 이전 방으로 돌아가고, 시험 적의 남은 체력과 미완료 상태가 유지된다. 실패하면 행동을 소모해 적의 차례가 진행된다. 승리하면 해당 조우가 완료되고 기존 방으로 복귀한다. 패배하면 타이틀로 돌아간다. 전투 후 체력은 유지되며 층 이동에 성공하면 회복된다. 탐험 중 I 또는 게임패드 북쪽 버튼으로 인벤토리를 열고 닫는다. 슬롯을 선택한 뒤 다른 슬롯을 선택하거나 마우스로 끌어 놓아 아이템을 이동·교환할 수 있다. 선택 중 취소하면 이동을 중단한다. 시험 아이템을 받을 공간이 없으면 새 아이템을 두고 가거나 기존 묶음을 선택해 확인 후 교체할 수 있다. 시험 소형 회복약은 탐험 인벤토리에서 체력을 최대 25 회복하며, 체력이 최대일 때는 소비되지 않는다. 보라색으로 표시된 문은 시험용 잠긴 문이며, 인벤토리에서 지급한 시험 열쇠 하나를 사용해 양방향으로 열 수 있다. 잠긴 문 앞에서 F 또는 게임패드 서쪽 버튼으로 공격력 판정을 통한 강제 개방을 한 번 시도할 수도 있다. 실패 후에도 열쇠로 열 수 있다. 현재 판정의 공격력 50과 문 난이도 50은 시험값이다.

오른쪽 위 미니맵은 현재 방과 방향을 초록색으로, 방문한 방을 밝은색으로 표시한다. 연결만 확인한 미방문 방은 어두운 윤곽으로 나타나며, 아직 확인하지 못한 방과 비밀 통로는 숨긴다. 새 게임을 시작하면 방문 기록이 초기화된다.

새 게임마다 일반 방 8~10개와 시작 방·계단 방·상위 개체 방이 연결된 1층 구조를 생성한다. 2층도 임시로 같은 생성 규칙을 사용하며 이전 층으로 돌아갈 수 없다. 3층과 전투 기술·보상·전체 게임 진행 저장은 후속 작업이다. 주인공과 슬라임 퀸 이미지는 개발용 시안이며 시험 적의 능력치는 임시값이다. 전투 중 시험 종료와 인벤토리의 시험 아이템·열쇠 지급은 개발 확인용 기능이다. 잠긴 문은 필수 경로가 아닌 일반 말단 방에 하나만 배치되며 해당 방이 없으면 배치하지 않는다. 정식 열쇠 획득과 아이템 사용·드롭은 후속 작업이다.

## 검증과 빌드

PowerShell에서 `Tools/Run-DayFortyTwoChecks.ps1 -Check EditMode`, `-Check PlayMode`, `-Check Build`로 실행한다. 편집기 경로가 다르면 `-UnityPath`로 지정한다. 플레이 화면을 창을 띄우지 않고 캡처하려면 `-Check Screenshot`을 사용한다. Windows 테스트 실행 파일 검증은 `-Check PlayerTests`를 사용한다. 원본 프로젝트가 Unity에서 열려 있으면 별도 프로젝트 복사본에서 테스트한다.

기본 씬 재생성은 Unity 메뉴 `Project Delta/1일차/기본 씬 재생성`으로 실행한다. 생성기는 해당 기본 씬 세 개를 덮어쓰므로 씬 편집 후에는 변경을 먼저 보존한다.

기존 던전에 이동 요소를 다시 연결하는 메뉴는 `Project Delta/2일차/던전 이동 구성`이다. 바닥이 완전히 비어 있을 때만 시험 바닥·장애물을 생성하며, 기존 바닥의 빈 칸과 사용자 장애물은 보존한다. 이전 시험 장애물과 정확히 일치하는 배치는 밝은 전용 타일로 교체한다. 다른 열린 씬의 미저장 변경은 저장 또는 취소를 확인한다.

두 시험 방을 연결하는 메뉴는 `Project Delta/3일차/시험 방 연결`이다. 기존 객체나 문 위치의 타일과 충돌하면 구성을 중단한다. 다른 열린 씬의 미저장 변경은 저장 또는 취소를 확인한다.

세 번째 방과 지도를 구성하는 메뉴는 `Project Delta/4일차/시험 방과 지도 구성`이다. 기존 방·문 설정이 시험 구성과 다르거나 새 출구 칸이 점유되어 있으면 구성을 중단한다.

검증 기록은 `Artifacts`, 42일차 Windows 빌드는 `Builds/Day42`에 생성되며 Git에서 제외한다. 기존 빌드도 각 일차의 경로에 남는다.
