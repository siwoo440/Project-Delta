# 5일차 1층 던전 생성 설계

---
## 목표

새 게임마다 1층의 방 좌표와 양방향 연결을 생성한다. 일반 방 8~10개와 시작 방·계단 방·상위 개체 방을 배치하고, 생성된 하나의 데이터로 실제 방 이동과 미니맵을 구성한다.

---
## 규칙

- 시작 방에서 계단 방까지 연결하고, 최단 연결 거리와 지도 좌표 거리를 각각 최소 다섯 칸으로 유지한다.
- 모든 일반 방과 필수 방은 시작 방에서 도달 가능하고, 방 좌표와 문 방향은 중복되지 않는다.
- 비밀 방, 순환 경로, 잠긴 문, 실제 계단 이동과 상위 개체 조우는 후속 작업이다.
- 실제 방은 기존 2D 시험 타일을 실행 중 복제하며 씬 원본을 변경하지 않는다.
- 시드가 같으면 방과 출구·종류가 재현되며, 일반 게임에는 시드 입력 UI를 추가하지 않는다.
- 생성 시도는 제한하고, 실패 시 같은 규칙으로 검증한 고정 대체 구조를 사용한다.
- 시작 방을 방문 처리하고 성공한 이동만 미니맵에 반영하며, 미발견 정보는 숨긴다.
- 미니맵 크기와 중심은 공개된 방만 기준으로 계산하여 숨겨진 방의 범위가 노출되지 않게 한다.
- 매 개발일의 README 플레이 화면은 해당 버전의 실제 Windows 실행 화면을 캡처해 갱신한다.

---
## 검증

다수의 시드와 대체 구조에서 방 수·필수 방·도달 가능성·계단 거리·반대 출구·재현성을 확인한다. 실제 씬에서 생성 방의 출구, 기존 이동과 미니맵, 새 게임 초기화, Windows 플레이 화면과 빌드를 검증한다.
