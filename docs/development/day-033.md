# 33일차: 미니맵 계단 표시

---
## 구현 내용

- 실제로 방문한 계단 방에 파란 계단 표시 추가.
- 연결만 확인한 계단 방의 종류는 방문 전까지 비공개 유지.
- 현재 방 중심의 미니맵 범위와 미발견 비밀 방 보호 유지.
- 실제 계단 방의 플레이 화면을 README에 반영.

---
## 범위

NPC와 보물 표시, 전체 지도는 아직 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 148개와 PlayMode 테스트 95개 통과.
- 실제 이동을 통한 계단 방 방문 전후 표시와 층 이동 검증.
- 계단 방 플레이 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
