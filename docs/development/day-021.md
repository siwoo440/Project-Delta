# 21일차: 관찰 기록 화면

---
## 구현 내용

- 타이틀에서 저장된 시험 대상의 관찰 기록을 확인하는 읽기 전용 화면 추가.
- 미관찰 상태에서는 상세 정보와 이미지를 숨기고, 관찰된 대상만 체력과 공격 성향 표시.
- 키보드와 게임패드로 열고 닫으며 닫은 뒤 타이틀 버튼 선택 복원.
- 저장 손상·복구 경고를 표시하고 도감 열람 중 저장 파일 유지.

---
## 범위

현재 도감은 시험 대상의 1단계 정보만 표시한다. 대상 발견 기록, 정식 도감 목록과 다단계 관찰 정보는 후속 작업이다. 그림과 능력치는 개발용 시안과 시험값이다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 131개와 PlayMode 테스트 69개 통과.
- 미관찰 정보 보호, 저장 기록의 재초기화 후 표시와 읽기 전용 동작 검증.
- 손상 저장 경고와 원본 보존, 키보드·게임패드 화면 열기와 닫기 검증.
- 실제 도감 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
