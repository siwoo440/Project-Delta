# 22일차: 인벤토리 슬롯 이동

---
## 구현 내용

- 기존 10칸에서 전체 아이템 묶음을 빈 슬롯으로 이동하거나 다른 묶음과 교환.
- 마우스 드래그 앤 드롭과 키보드·게임패드의 출발·도착 슬롯 선택 지원.
- 같은 칸 선택, 드래그 바깥 놓기와 취소 시 기존 아이템 보존.
- 드래그 중 다른 아이템 변경을 차단하고 식별자·수량·중첩 한도 유지.
- 현재 기획서의 마우스 드래그와 키보드·게임패드 선택 이동 규칙 반영.

---
## 범위

회차 인벤토리 저장·복원과 가방 확장은 후속 작업이다. 기획서 이전 버전을 읽는 요청이 실패해 이번 확인에서 변경 전후의 정확한 차이는 확인하지 못했다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 133개와 PlayMode 테스트 74개 통과.
- 빈 칸 이동, 아이템 교환과 수량·중첩 한도 보존 검증.
- 키보드와 게임패드 선택, 가상 마우스 드래그, 취소 및 중복 입력 방지 검증.
- 실제 인벤토리 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
