# 9일차 기본 공격과 승패 설계

---
## 목표와 규칙

- 기존 전투 규칙에 따라 기본 공격의 명중률을 `70 + 명중 - 회피 × 50%`로 계산하고 5~95%로 제한한다.
- 명중 피해는 `공격 × 100 / (100 + 방어)`에 95~105% 편차를 적용하고 최소 1로 제한한다.
- 플레이어와 적의 체력 감소와 생존 상태를 반영하고 플레이어 사망을 패배, 적 전멸을 승리로 처리한다. 상호 전멸 시 패배가 우선이다.
- 실제 전투 화면에서 기본 공격과 결과를 표시하고 승리 시 해당 방의 시험 조우를 완료한다.
- 전투 후 플레이어 체력은 같은 탐험에서 유지한다. 새 게임은 기존 프로젝트의 기본 체력으로 초기화한다.
- 현재 참가자 능력치는 원본 데이터 연동 전의 시험값이다. 기술·방어 행동·보상·저장은 후속 작업이다.
- 무작위 결과를 테스트에서 제어할 수 있게 분리하고 사용자 화면을 조작하지 않는다.

## 기준

기존 BattleDamageCalculator, BattleOutcomeEvaluator, PlayerRunState 및 전투 완료 처리의 규칙을 확인해 새 코드로 작성한다.
