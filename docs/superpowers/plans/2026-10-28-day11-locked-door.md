# 11일차 잠긴 문과 열쇠 구현 계획

**목표:** 시험 잠긴 문을 기존 열쇠 소모 규칙으로 열고 방 이동 실패 시 상태를 보존한다.

**구조:** Core에서 열쇠 수와 방 연결의 양방향 잠금 상태를 관리하고 Runtime에서 표시·입력·이동을 연결한다.

---
## 순서

1. 열쇠 수, 양방향 잠금, 열쇠 부족과 중복 열기의 실패 테스트 작성 후 규칙 구현.
2. 시험 잠긴 문을 선택하고 실제 문 표시·열쇠 안내 및 시험 열쇠 지급을 연결.
3. 실제 입력으로 열쇠 없음·도착 실패 복구·성공·역방향 재이용을 검증.
4. 전체 테스트, 최신 화면과 Windows 빌드를 별도 프로젝트에서 검증하고 커밋·푸시.

---
## 제한

- 말단 일반 방이 없는 구조에서는 시험 잠긴 문을 만들지 않는다.
- 강제 개방과 정식 열쇠 획득·저장은 후속 작업이다.
- 방 이동 실패 시 열쇠와 잠금 상태, 기존 씬과 사용자 입력을 보존한다.
