# 8일차 전투 라운드 구현 계획

**목표:** 참가자의 속도와 동률 우선순위에 따른 라운드 진행을 전투 화면에서 확인한다.

**구조:** 참가자와 행동 순서·라운드 상태는 Core에 두고 Runtime 화면은 상태를 표시하고 시험 진행 입력을 전달한다.

**환경:** Unity 6000.3.21f1, URP 2D, C#.

---
## 순서

1. 순서·동률·사망 제외·라운드 경계의 실패 테스트를 작성하고 규칙 구현.
2. 시험 전투 화면에 라운드와 행동자를 연결하고 실제 UI 입력 통합 테스트 작성.
3. 기존 전투 진입과 탐험 복귀, EditMode·PlayMode·스크린샷·Windows 빌드를 검증.
4. 최신 실제 전투 화면과 작업 기록을 갱신하고 지정 형식으로 커밋·푸시.

---
## 제한

- 참가자 능력치와 상태 이상 효과는 아직 없으므로 실제 데이터 대신 시험값 사용.
- 공격·방어·피해·승패·보상은 구현하지 않음.
- 실제 검증 없이 성공을 주장하지 않으며 사용자 화면은 조작하지 않음.
