# 61일차 : 시험 아이템과 인벤토리 확장

---
## 개발 내용

- 시험 소형·대형 체력 회복약과 마나 회복약의 획득 및 탐험·전투 사용 추가
- 회복 효과가 없는 사용에서 아이템과 전투 행동 보존 추가
- 전체 아이템 묶음 버리기 확인 및 기본 아니요 선택 추가
- 가방이 가득 찬 승리 보상의 기존 묶음 교체 확인 추가
- 선택한 묶음이 확인 중 바뀌면 버리기와 교체 중단 추가
- 승리 보상의 아이템 종류 저장 및 기존 저장의 소형 회복약 호환 수정
- 실제 플레이 화면 갱신

---
## 시험 범위

- 체력 회복량은 소형 25, 대형 60, 마나 회복량은 30이며 묶음 한도 5개는 시험값이다.
- 회복약 보상 종류는 세 종류 중 시험 추첨으로 결정되며 저장 후 다시 열어도 유지된다.
- 정식 아이템 목록, 드롭 확률, 장비와 유물 보상은 추후 확정이 필요하다.

---
## 검증

- Unity 6000.3.21f1 EditMode 267개 통과
- Unity 6000.3.21f1 PlayMode 133개 통과
- 버리기·보상 교체·전투 아이템·보상 복원 집중 검증 4개 통과
