# 6일차 계단과 층 이동 설계

---
## 목표와 규칙

- 계단 방의 중앙 계단 칸에 서서 E 또는 게임패드 남쪽 버튼으로 다음 층으로 이동한다.
- 2층도 1층의 방 생성 규칙을 우선 사용한다. 원래 기획 확인 전까지 임시 규칙이다.
- 이전 층으로 돌아가지 않으며 3층 이동은 규칙 확인 전까지 막는다. 새 층의 발견 기록은 새로 만들고 시작 방만 방문 처리한다.
- 층 이동 중 중복 입력을 막고 생성 실패 시 이전 층과 위치를 유지한다.
- 새 게임은 1층에서 시작한다. 층 번호와 현재 방을 표시한다.
- 기존 씬 파일과 사용자 설정을 보존하고 실행 중 복제한 방으로 층을 구성한다.
- 사용자가 Unity를 사용 중이므로 별도 프로젝트에서 화면을 띄우지 않고 검증한다.

---
## 검증

계단 위치와 입력, 이동 중 입력, 층 이동 성공 및 실패 복구, 미니맵의 독립 방문 기록, 새 게임 초기화와 기존 방 이동을 검증한다. 최신 게임 카메라와 UI 화면을 화면 밖에서 캡처해 README를 갱신한다.
