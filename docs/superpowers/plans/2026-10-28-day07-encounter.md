# 7일차 조우와 전투 화면 구현 계획

**목표:** 시험 조우에서 전투 화면을 열고 원래 탐험 상태로 복귀한다.

**구조:** Core에서 탐험과 전투 상태 전환을 검증하고 Runtime에서 시험 대상을 생성하며 UI 화면과 입력을 제어한다. 기존 던전 씬은 보존한다.

**환경:** Unity 6000.3.21f1, URP 2D, C#.

---
## 구현과 검증

1. 탐험에서만 전투 진입, 중복 진입 거절, 전투 종료와 복귀의 실패 테스트 작성 후 상태 구현.
2. 상위 개체 방의 시험 대상과 이동 종료 시 자동 조우, 별도 전투 화면과 탐험 입력 잠금 구현.
3. 실제 키 입력으로 상위 개체 방 진입·전투 화면 표시·종료 후 탐험 상태 보존을 검증.
4. EditMode·PlayMode·화면 캡처·Windows 빌드를 화면 없는 별도 프로젝트에서 실행.
5. 최신 화면과 개발 기록을 반영하고 지정 형식으로 커밋·푸시.

---
## 유의 사항

- 원래 전투 판정과 승패 규칙이 확인되지 않아 이번 범위에서 제외.
- 기존 2층 임시 규칙과 미발견 방 표시 보호.
- 열린 원본 Unity 프로젝트와 사용자 설정 보존.
