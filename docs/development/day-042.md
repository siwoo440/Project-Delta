# 42일차: 회차 탐험 기록 화면

---
## 구현 내용

- 현재 회차의 전체 탐험 기록을 시간순으로 한 페이지에 여덟 개씩 표시.
- H 키, 게임패드 왼쪽 스틱 버튼 또는 탐험 화면 버튼으로 기록 화면 열기.
- 기록 화면에서 방향키·게임패드 방향 버튼·마우스로 페이지 이동.
- 기록 화면을 닫을 때 기존 탐험 입력 복구.
- 실제 방 이동 기록 화면을 README에 갱신.

---
## 범위

현재는 임시 기록 화면 진입을 사용하며 정식 일시 정지 메뉴와 파일 저장은 아직 구현하지 않았다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 151개와 PlayMode 테스트 103개 통과.
- 키보드·게임패드·마우스 입력, 페이지 이동과 탐험 복귀 검증.
- 실제 기록 화면 캡처와 Windows 빌드 성공. 사용자 화면 보호를 위해 실행 파일 테스트는 실행하지 않음.
