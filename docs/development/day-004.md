# 4일차: 시험 방 정보와 방문 미니맵

---
## 구현 내용

- 씬 객체와 분리된 방 정의·양방향 출구·방문 기록 추가.
- 기존 두 방에 세 번째 시험 방을 연결하고 같은 방 정보로 이동과 지도 구성.
- 시작 방 방문 처리와 성공한 방 이동 후 방문 기록 갱신.
- 현재 방·방향, 방문 방, 연결만 확인한 미방문 방의 미니맵 표시.
- 미발견 방과 비밀 방·비밀 연결 정보 가림.
- 실제 비밀 연결을 통과한 이후에만 연결 정보 공개.
- 도착 실패 시 위치·방문 기록·지도 표시 보존.
- 새 게임 시작 시 방문 기록 초기화.
- 사용자 방·문 설정, 출구 타일과 미저장 씬의 보존 처리.
- 이전 실행 파일과 분리된 `Builds/Day04` Windows 빌드 경로 추가.

---
## 지도 표시

현재 방은 초록색과 방향 화살표, 방문 방은 밝은색, 연결만 확인한 미방문 방은 어두운 윤곽으로 표시한다. 아직 확인하지 못한 방이나 비밀 통로는 표시하지 않는다.

---
## 검증 대상

출구 연결의 양방향 일치, 방문과 새 게임 초기화, 비밀 방·비밀 연결 가림, 실패한 방 이동, 세 시험 방의 왕복, 기존 사용자 씬 보존과 Windows 화면을 확인한다.

- Unity EditMode 테스트 48개 통과.
- Unity PlayMode 테스트 23개 통과.
- Windows 테스트 실행 파일에서 테스트 26개 통과. 실제 화면의 미니맵 표시 확인 포함.
- Windows 일반 실행 파일 빌드 완료: `Builds/Day04/ProjectDelta.exe`.

---
## 후속 범위

무작위 던전 생성, 비밀벽 발견·개방, 지도 정보 구매, 전체 지도 조작과 저장·불러오기는 이후 작업이다. 이번 방문 기록은 게임 실행 중에만 유지된다.
