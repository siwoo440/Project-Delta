# 10일차 인벤토리 기본 구조 설계

---
## 목표와 규칙

- 기존 프로젝트와 같이 기본 10칸의 인벤토리를 새 코드로 작성한다.
- 아이템을 획득할 때 같은 아이템의 기존 묶음을 먼저 채우고 남은 수량을 빈 슬롯에 넣는다.
- 각 묶음의 최대 개수를 지키며 공간 부족 시 추가되지 않은 수량을 결과로 돌려준다.
- 탐험 중 I 또는 게임패드 북쪽 버튼으로 인벤토리를 열고 닫으며 탐험 위치와 현재 층을 보존한다.
- 화면의 시험 아이템 획득은 개발 확인용이다. 정식 드롭·상자·아이템 사용과 저장은 후속 작업이다.
- 인벤토리는 같은 게임의 층 이동 중 유지하며 새 게임에서는 빈 10칸으로 초기화한다.
- 인벤토리가 열려 있을 때 탐험 입력과 조우 처리를 잠근다.

---
## 기준

원본 InventoryRunState와 InventoryAcquisitionService의 기본 슬롯 수, 중첩 및 남은 수량 규칙을 참고하고 구현 코드는 새로 작성한다.
