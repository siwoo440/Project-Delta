# 62일차 : 장비 장착과 저장 추가

---
## 개발 내용

- 무기·방어구·장신구·가방의 장착, 교체, 해제 추가
- 시험 검·도끼·경갑·전투 장신구·낡은 주머니 추가
- 장비 공격력·방어력·속도와 무기별 치명타 확률·배율의 전투 반영 추가
- 가방 용량 확장과 축소 시 아이템 보존 및 공간 부족 차단 추가
- 장비 변경 자동 저장, 저장 충돌 시 변경 취소, 이전 회차 복원 추가
- 확장된 인벤토리와 보상·전투 아이템 화면 표시 수정
- 최신 실제 플레이 화면 갱신

---
## 시험 범위

- 장비 수치는 기획서의 시험값이며 장비는 개발 확인용 지급 버튼으로 획득한다.
- 희귀도, 무작위 옵션, 저주와 정식 획득 경로는 후속 범위다.
- 새 회차에는 장비가 지급되지 않으며 장비는 회차 저장에 포함된다.

---
## 검증

- Unity 6000.3.21f1 EditMode 275개 통과
- 장비 교체·저장 충돌·전투 반영 집중 PlayMode 3개 통과
- 수정 후 전체 PlayMode 136개 통과
- 확장 가방의 전투 목록과 키보드·게임패드 조작 포함 집중 검증 5개 통과
