# 20일차: 조우 회유 구현

---
## 구현 내용

- 플레이어 매력과 대상 저항에 각각 보정과 1~20 주사위를 더해 회유 판정하며 동점은 성공.
- 시험 대상의 회유 성공은 보상 없이 평화적으로 조우를 완료하고 실패는 일반 전투로 연결.
- 실제 대상이 없는 조우에서는 회유를 차단하고 성공·실패 처리 오류 시 판정을 보존.
- 조우 선택을 네 버튼으로 확장하고 좁은 화면과 키보드·게임패드 입력 대응.
- 기존 3D 전투 회유는 백분율 기반이지만 2D 조우 판정은 사용자가 제공한 기획서의 양쪽 주사위 기준 적용.

---
## 범위

매력 10과 저항 10은 시험값이다. 정식 몬스터별 회유 가능 여부, 적대·아이템 보정과 대상별 결과는 후속 작업이다. 회유의 시험 성공 결과는 대상 제거 외의 관계 변화나 보상을 지급하지 않는다.

---
## 검증 결과

- 별도 Unity 프로젝트에서 EditMode 테스트 131개와 PlayMode 테스트 66개 통과.
- 회유 판정 경계·보정·동점, 키보드·게임패드 선택, 성공·실패와 처리 재시도 검증.
- 실제 조우 화면 캡처 테스트 통과와 Windows 빌드 성공.
- 사용자 화면을 보호하기 위해 Windows 실행 파일 테스트는 실행하지 않음.
