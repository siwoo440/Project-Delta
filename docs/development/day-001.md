작업 시작: 2026-10-26. 최종 검증: 2026-10-28.

## 구현 결과

- 기존 기획의 기능·규칙을 기준으로 신규 C# 실행 구조 작성.
- Bootstrap → Title → 새 게임 → Dungeon 흐름과 Esc 복귀.
- 공통 AppRoot·EventSystem 단일 유지, 전환 중 중복 요청 차단.
- 타이틀 UI와 탐험 입력 맵 분리, 전환 중 입력 잠금.
- 한글 타이틀과 새 게임 버튼, 2D 격자·정지 플레이어 표시.
- 배경 클릭 후 키보드·게임패드 선택 유지.
- 씬 생성·Windows 빌드·반복 검증 도구 추가.
- Unity 캐시·개인 설정·빌드 출력 제외와 Git 기준 구성.

## 검토와 수정

배경 클릭 후 기본 버튼 선택이 사라지는 문제를 실제 마우스 입력으로 재현하고 수정했다. 자동 테스트에서는 편집기 창 포커스와 관계없이 검증 장치 입력을 게임에 전달하며 검증 후 원래 설정을 복구한다.

검증 도구는 이전 XML을 지우고 새 결과·실행 개수·실패 수를 검사한다. Windows PowerShell 5.1에서도 한글 주석을 읽도록 UTF-8 BOM을 적용했다.

## 범위와 후속 작업

이동·충돌·전투·저장 기능은 아직 구현하지 않았다. 다음 작업은 2D 격자 이동, 점유 검사, 4방향 표시다.

씬 로드 실패 복구는 상태 모델과 로더 단위로 검증했다. 전체 AppRoot와 UI를 함께 거치는 실패 복구의 추가 통합 검증은 후속 검증 대상이다. 편집 중 씬 등록을 바꾸는 방식은 실행 중인 빌드 씬 목록을 바꾸지 못하므로 해당 검사에 사용하지 않는다.
